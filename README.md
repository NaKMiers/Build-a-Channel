## Workspace Organization

Use these boundaries:

- `video-projects/` for one video's working memory and production decisions
- `common/` for reusable systems that should improve many videos
- `docs/` for channel-level memory, strategy, guardrails, and compact summaries
- `video-projects/<slug>/hyperframes/` for the current working HyperFrames source per video
- `remotion-studio/` is legacy and should stay untouched until deletion is requested

For an active video, prefer updating `video-projects/<slug>/` before creating scattered notes elsewhere.

## Current Direction

- Channel name: `Why It Works`
- Primary language: `English`
- Format: `no-face explainer channel`
- Main audience lens: `English learners who want interesting, useful English through clear explainers`
- Core subject area: `money, internet, society, business, and modern life`
- Tone: `smart, simple, funny, dry, curiosity-driven`

## One-Sentence Positioning

`Why It Works` explains money, the internet, and modern life in simple, funny English that English learners can enjoy without feeling like they are studying.

## Safety Rule

No new idea should become "core channel strategy" unless it passes the guardrails in [docs/channel-guardrails.md](C:\ME\THINGS\Build a Channel\docs\channel-guardrails.md).
