# Mascot Pose Library (reference: "Vui Vẻ"-style host)

Reference pose set extracted from a Vui Vẻ-style Vietnamese explainer. Used as the **emotional + role range target** for the `Why It Works` mascot (WIT). It is a casting sheet, not art to copy 1:1.

## How an AI should use this file

1. Read the spoken line / beat for the scene.
2. Decide the **emotion** the narrator is carrying on that line (curious, smug, shocked, tired…).
3. Use the **Quick index** to jump to candidate poses, then read each pose's **Use when** to pick the best fit.
4. Prefer **show-as-you-say**: change the pose on the beat where the emotion changes (per the channel rule "illustrate per sentence, not per section").
5. Match framing: `closeup` poses = focus/punchline beats; full-body/`presenting` poses = intros and example setups; `prop/role` poses = when the line names that role or object.

Each entry: `![name](file.png)` + **Emotion**, **Body / expression**, **Use when**.

> File location: `analysis/vuive poses/`. All image paths below are relative to this file.
> Two poses referenced in earlier notes are NOT on disk (lost during a file add): `holding_phone_pointing_smile`, `smug_smirk_closeup`. Re-add them if needed.
