# Why It Works Thumbnail Packaging System

Classification: `Core`

Scope: `CHANNEL_WIDE`

Purpose:
make every future `Why It Works` video earn curiosity before the viewer clicks.

This system applies to future packaging work. It does not create or approve packaging for any existing video project.

## Core Standard

A strong `Why It Works` package should do two things at the same time:

1. Let a stranger understand the topic in `1` second.
2. Leave that stranger with a question.

Working rule:

`The thumbnail shows the weird situation. The title names the hidden logic.`

If the thumbnail only explains the topic, it is too flat.
If the title and thumbnail say the same thing, one of them is wasted.

## Default Thumbnail Formula

Use this formula first:

```text
one real object + one contradiction + one WIT emotion + one short label
```

The four parts:

- `real object`: phone, wallet, receipt, cart, checklist, chair, bill, box, app screen, calendar, price tag
- `contradiction`: free but costly, cheap but worse, convenient but expensive, productive but trapped, simple but confusing
- `WIT emotion`: suspicious, betrayed, trapped, panicked, confused, defeated
- `short label`: `1-3` words, usually a question or fake label

The thumbnail should make the viewer ask:

```text
What is going on here?
Why does that normal thing look suspicious?
What happened to WIT?
```

## Title Role

The title should not describe the drawing.
It should frame the larger idea behind the drawing.

Good title jobs:

- name the hidden cost
- state the contradiction
- make a normal thing feel strange
- promise a system-level explanation
- use simple English that an intermediate learner can follow

Avoid titles that sound like generic advice, finance tips, productivity advice, or business essays.

## Title Formulas

Use these as starting structures:

```text
Why [normal thing] Is Not Really [simple belief]
Why [normal thing] Feels So [emotion/problem]
The Hidden Cost Of [normal thing]
How [normal thing] Quietly Became [weird outcome]
Why [normal thing] Keeps Getting Worse
Why [annoying behavior] Makes Perfect Sense
The Strange Logic Behind [normal thing]
```

Title quality checks:

- Is it specific enough that another channel could not use it unchanged?
- Does it imply a hidden system instead of a personal opinion?
- Does it use common words before fancy words?
- Does it create curiosity without fake drama?
- Does it avoid repeating the exact thumbnail label?

## Pairing Rule

Every package needs a title-thumbnail pair, not two separate ideas.

Use this pairing structure:

| Element | Job | Should answer |
| --- | --- | --- |
| Title | Names the hidden logic | `What is this really about?` |
| Thumbnail | Shows the weird situation | `Why does this look wrong?` |
| WIT | Shows the human feeling | `How does this system feel?` |
| First 10 seconds | Pays off the click | `Did the video prove the promise?` |

Bad pair:

```text
Title: Why [thing] Is Expensive
Thumbnail label: EXPENSIVE?
```

Better pair:

```text
Title: The Hidden Cost Of [thing]
Thumbnail label: [CLAIM]?
```

The better pair creates a gap between what the viewer sees and what the title explains.

## Packaging Workflow

Do this before scripting:

1. Write the plain topic in one sentence.
2. Identify the main contradiction.
3. Generate `10` title ideas.
4. Generate `5` thumbnail concepts.
5. Pick the strongest title-thumbnail pair.
6. Write the first `10` seconds to satisfy the thumbnail promise.
7. Define the recurring visual motif.
8. Reject concepts that are clear but boring.

Do this before production:

1. Make a rough thumbnail mockup.
2. Shrink it to mobile size.
3. Check whether the object, WIT emotion, and label still read.
4. Compare it beside reference thumbnails.
5. Rewrite the title if the title and thumbnail repeat each other.
6. Score the package with [packaging-scorecard.md](packaging-scorecard.md).

## First 10 Seconds Rule

The opening must prove that the click was worth it.

If the thumbnail shows a suspicious object, the first `10` seconds should show that object or the exact contradiction behind it.

If WIT is betrayed, trapped, or panicked in the thumbnail, the hook should explain what betrayed, trapped, or attacked him.

Do not open with a slow definition if the thumbnail promised a weird situation.

## Recurring Visual Motifs

Use one motif per video so the package connects to the actual visual system.

Good motif types:

- `hidden checkout`: normal object has a secret payment point
- `leaking wallet`: money escapes through tiny invisible holes
- `trap interface`: a simple screen becomes a cage
- `receipt storm`: small costs pile into a physical mess
- `fake bargain`: the discount tag hides the downgrade
- `attention shelf`: time or attention becomes a sellable product
- `product downgrade`: the object looks cheaper, thinner, smaller, or worse
- `monthly leash`: repeated payments act like a cord or chain

The motif should appear in:

- thumbnail
- first `10` seconds
- at least one later section
- final payoff if natural

## WIT In Packaging

Thumbnail WIT must have one clear emotion:

- suspicious
- betrayed
- trapped
- panicked
- confused
- defeated

Avoid neutral WIT in thumbnails.

WIT should not be a presenter in thumbnails.
WIT should look like a normal person experiencing the system.

Working rule:

`Thumbnail WIT is the viewer's emotional shortcut.`

## Label Rules

Thumbnail text should be:

- `1-3` words
- readable at mobile size
- handwritten-looking when possible
- emotionally loaded but honest
- different from the title

Good label types:

```text
[WORD]?
[PRICE]?
[CLAIM]*
NOT [CLAIM]
WHY?
BROKEN?
```

Avoid:

- long phrases
- full-sentence explanations
- title repeated as thumbnail text
- abstract labels that do not attach to the object
- many arrows competing for attention

## Rejection Rules

Reject a package if:

- the thumbnail looks like a clean presentation slide
- WIT has no emotion
- the object is generic and could fit any topic
- the title could belong to any finance or productivity channel
- the image answers everything with no open question
- the title relies on fake urgency or rage bait
- the first `10` seconds cannot naturally pay off the thumbnail
