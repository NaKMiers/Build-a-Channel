# English Learner Script Checklist

Classification: `Core`

Scope: `CHANNEL_WIDE`

Purpose:
give every future `Why It Works` script a reusable learner-clarity gate before voiceover, board planning, or production.

This checklist is reusable. It must not be filled out for an existing video unless the user explicitly asks to apply the channel-wide system to that video project.

## Script Decision

Use this result:

```text
PASS: clear enough to move forward
FIX: revise listed sections, then check again
FAIL: the script is not ready for voiceover or board planning
```

## 1. Topic Sentence

```text
[ ] the video has one clear question
[ ] the topic can be explained in one simple sentence
[ ] the main problem is concrete, not only abstract
[ ] the viewer can tell why this matters in daily life
```

Pass only if the main idea can be said simply:

```text
This video explains why _____ happens, and why it matters.
```

```text

```

## 2. Structure

```text
[ ] hook creates a visible contradiction
[ ] reframe says what the video is really about
[ ] body has `3-5` clear sections
[ ] each section starts from one idea
[ ] section transitions tell the viewer where they are going next
[ ] ending gives one repeatable final insight
```

Hard fail:
the script changes direction without signposts.

Decision:

```text
Structure: PASS / FIX / FAIL
Required fix:
```

## 3. Sentence Clarity

```text
[ ] most sentences are short enough to read aloud comfortably
[ ] long sentences are broken before voiceover
[ ] common words appear before technical words
[ ] abstract ideas are followed by concrete examples
[ ] no sentence contains too many causes, examples, and jokes at once
```

Useful rewrite pattern:

```text
Dense line:
_____

Simpler version:
First, _____.
That matters because _____.
You can see it when _____.
```

Decision:

```text
Sentence clarity: PASS / FIX / FAIL
Required fix:
```

## 4. Key Terms

```text
[ ] important terms are introduced with context
[ ] unexplained acronyms are removed or explained naturally
[ ] key terms repeat across the video
[ ] each section has one short label candidate
[ ] repeated phrases are useful, not decorative
```

Good labels are short:

```text
hidden cost
easy entry
the long game
not really free
monthly leak
```

Hard fail:
an important term appears once, carries the explanation, and then disappears.

Decision:

```text
Key terms: PASS / FIX / FAIL
Required fix:
```

## 5. Useful Phrase Layer

```text
[ ] `3-5` useful phrases are selected
[ ] phrases are useful outside the video
[ ] phrases appear naturally in narration
[ ] phrases can become on-screen labels
[ ] at least one phrase returns near the payoff
[ ] no phrase is inserted only because it sounds educational
```

## 6. Idioms, Slang, And Cultural References

```text
[ ] no section stacks multiple idioms
[ ] slang is limited and understandable from context
[ ] cultural references are optional, not required for meaning
[ ] native-speaker jokes have visual support
[ ] acronyms and business terms are not assumed knowledge
```

Risky line types:

```text
This is a no-brainer, until the app pulls a bait-and-switch and you get FOMO'd into upgrading.
```

Cleaner version:

```text
The app makes the first step easy. Then it makes leaving feel annoying.
```

```text

```

```text
[ ] main point can be understood without the joke
[ ] jokes come from the situation, object, or WIT reaction
[ ] sarcasm is supported by visuals or immediate correction
[ ] wordplay is optional, not central
[ ] punchlines use simple words
[ ] no joke hides a key explanation
```

## 8. Voice Readiness

```text
[ ] first `45-60` seconds are marked for voice test
[ ] dense lines are marked with `[slower]` or `[pause]`
[ ] punchlines are marked with `[deadpan]` or `[beat]`
[ ] cue words are marked with `[emphasis]`
[ ] no line depends on being read too fast
[ ] script still works at a moderate learner-friendly pace
```

Hard fail:
the script only feels funny when delivered too quickly for learners.

## Pass Standard

The script passes when a learner can answer:

- What is this video about?
- What is the main problem?
- What are the `3-5` key phrases?
- Why is the system weird?
- What is the final insight?

If the answer depends on understanding every joke, the script is not clear enough.
