# Image Generation Tool

Purpose:
generate or prepare visual assets such as thumbnails, character references, and reusable illustrations.

## Current Status

No single locked image-generation tool is established yet.

## Rules

- Use generated images only when they improve clarity or production speed.
- Store one-off assets in `video-projects/<slug>/assets/`.
- Store reusable brand assets in `common/assets/`.
- Avoid real app logos unless there is a deliberate fair-use decision.
- Keep thumbnails simple enough to read at small size.

## Future Standard

When the workflow stabilizes, document:

- prompt format
- output folder convention
- thumbnail export sizes
- character reference process
- review checklist
