# Scene Grammar System

This is the channel-wide scene grammar for `Why It Works`.

Use it for future video planning, visual plans, HyperFrames boards, and rough-cut review. It does not convert any existing script into boards and does not apply to a specific `video-projects/` folder unless the user explicitly asks.

## Core Rule

`Static drawing -> narration twist -> red markup or hard cut -> next static drawing.`

The video should feel alive because the idea changes at the right moment, not because every object is moving.

## One-Board Contract

Every board should have:

- one thought
- one visual joke or one clear evidence object
- one WIT reaction or one real-life object
- one readable text label
- one clean timing beat

If a board needs two full sentences, three labels, and several unrelated objects to make sense, split or simplify it.

## Default Scene Pattern

Use this pattern often:

1. Show what people think.
2. Red-correct it.
3. Show what is actually happening.
4. Let WIT react.
5. Cut to the next example.

Default visual flow:

```text
OBVIOUS MEANING
red cross-out
REAL MEANING
WIT suspicious
hard cut
```

Example:

```text
FREE APP
red cross-out over FREE
PAY LATER
WIT holding a tiny receipt
hard cut to fake checkout
```

## Scene Functions

Use boards by function, not by sentence count.

### 1. Situation Board

Shows the normal thing the viewer recognizes.

Use for:

- hooks
- setup
- everyday examples
- "what people think"

Good ingredients:

- one familiar object
- one short label
- neutral or mildly suspicious WIT

### 2. Suspicion Board

Adds the weird detail.

Use for:

- hidden fees
- strange incentives
- a contradiction
- a suspicious asterisk

Good ingredients:

- red circle, underline, or arrow
- one wrong-looking detail
- WIT noticing the problem

### 3. Correction Board

Crosses out the obvious meaning and replaces it with the real meaning.

Use for:

- reframes
- "not this, actually this"
- business-model explanations
- language-simple clarifications

Good ingredients:

- red cross-out
- before/after label
- small payoff phrase

### 4. Mechanism Board

Shows how the system works.

Use for:

- money flows
- attention flows
- platform incentives
- feedback loops

Good ingredients:

- fake diagram
- three nodes max
- one bad arrow or one reveal
- WIT caught inside the system

### 5. Evidence Board

Shows a real or real-looking object that makes the idea tangible.

Use for:

- receipts
- phone screens
- bills
- app mockups
- paper notes
- screenshots recreated as mockups

Good ingredients:

- one dominant real-life object
- one stupid label or red markup
- no private data or real brand dependency

### 6. Reaction Board

Lets WIT carry the emotional beat.

Use for:

- punchlines
- viewer pain
- "this is where things get stupid"
- transitions after a dense idea

Good ingredients:

- one strong WIT emotion
- one prop
- one short label

### 7. Payoff Board

Turns the explanation into the final simple insight.

Use for:

- section endings
- final thesis
- topic payoff

Good ingredients:

- one clean phrase
- one visual metaphor
- less clutter than the section before it

## Section Grammar

For each `20-30` second section, use `3-6` meaningful boards.

Default section shape:

```text
1. recognizable situation
2. suspicious detail
3. real mechanism
4. WIT consequence or real object evidence
5. payoff label
```

Short connected ideas can stay inside one board with timed labels. Do not split every spoken phrase into a separate board.

## Board Count Guidance

For a `3-5` minute video:

- first `10` seconds: about `4` boards
- each `20-30` second section: `3-6` boards
- full video: roughly `45-75` meaningful boards

More boards are not automatically better. A board counts only if it changes the idea, joke, example, or evidence.

## Text Rules

Prefer labels like:

- `FREE*`
- `later`
- `attention inventory`
- `bad idea`
- `monthly pain`
- `checkout moved`
- `not a gift`

Avoid:

- long subtitle-like explanations
- full sentences copied from narration
- labels that say the same thing as the voice without adding a joke, contrast, or useful keyword
- more than three competing labels on one paused frame

## WIT Rules

WIT should have a job.

Good jobs:

- being charged by the system
- noticing the contradiction
- pointing at the suspicious detail
- suffering the consequence
- holding the evidence
- misunderstanding the fake promise in a funny way

Bad jobs:

- standing beside text as decoration
- smiling while the narration says something painful
- reacting before the script reveals the problem
- facing away from the important object

Use the WIT system in [docs/branding/wit-channel-system.md](../docs/branding/wit-channel-system.md) and [common/assets/wit/usage-rules.md](assets/wit/usage-rules.md).

## Real-Life Texture Rules

Every section should consider whether one real-life or real-looking object would make the idea clearer.

Good objects:

- receipt
- bill
- checkout screen
- phone mockup
- calendar
- paper note
- desk object
- fake notification

Use [real-life-visual-asset-system.md](real-life-visual-asset-system.md) for source safety and asset decisions.

## Motion Rules

Allowed motion:

- hard cut
- red marker draw
- small pop-in label
- tiny WIT shake
- receipt printing
- phone buzz
- simple reveal
- cue-timed underline

Avoid:

- decorative bouncing
- unnecessary slides
- complex transitions
- constant WIT movement
- object motion that does not land a joke or clarify the explanation

## Paused-Frame Gate

Before a board is approved, pause it and ask:

- Can I understand the main idea without hearing the whole sentence?
- Is there a joke, contradiction, or clear evidence?
- Does WIT's emotion match the narration at this exact beat?
- Is the text readable at mobile size?
- Is there one main idea, not three?
- Does the cut or emphasis arrive on the spoken beat?

If the frame has no joke and no evidence, revise it.

## Common Failure Modes

- clean board with no joke
- abstract label with no object
- WIT used as decoration
- too many full sentences
- too many boards for one connected idea
- motion added because the frame feels empty
- real-life asset used as decoration instead of evidence
- punchline visible before the narration lands

## Future Production Rule

When turning a future script into visuals:

1. Identify the section's one thought.
2. Pick the board function.
3. Pick one visual humor pattern.
4. Pick WIT or a real-life object as the anchor.
5. Write one short label.
6. Place the cut, popup, underline, or red markup on the spoken beat.
7. Check the paused frame.
