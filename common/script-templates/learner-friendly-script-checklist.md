# Learner-Friendly Script Checklist

Classification: `Core`

Scope: `CHANNEL_WIDE`

Use this checklist before a future `Why It Works` script moves into voiceover or HyperFrames production.

The channel should feel like real English YouTube that English learners can follow, not an English lesson.

## Core Rule

Teach the topic first.
Make the English learner-friendly by design.

The viewer should understand the main point even if they miss one joke.

| Check | Pass? | Notes |
|---|---|---|
| The video has one clear question |  |  |

| Jokes work from context |  |  |

## Sentence Rules

Prefer:

```text
One idea per sentence.
One turn per paragraph.
Short setup, short punchline.
Clear subject, clear verb.
```

Avoid:

```text
Long chains of clauses.
Abstract nouns stacked together.
Three examples in one sentence.
Jokes that depend on fast wordplay.
```

Good:

```text
The app is not free. It just moved the price.
```

Too dense:

```text
The perceived absence of payment creates a behavioral environment where users underestimate the exchange taking place.
```

## Word Choice Rules

Use common words first.

| Prefer | Avoid Unless Needed |
|---|---|
| use | utilize |
| buy | purchase |
| help | facilitate |
| make money from | monetize |
| keep you watching | increase retention |
| hidden cost | indirect exchange |
| simple | frictionless |
| trick | behavioral mechanism |

Technical words are allowed when useful, but explain them quickly.

Pattern:

```text
The business word is _____.
The normal human version is _____.
```

## Structure Rules

Use signposts so learners never feel lost.

Good signposts:

```text
First, _____.
Second, _____.
This is where it gets weird.
Here is the trick.
The real problem is _____.
So the bigger point is _____.
```

Avoid:

- jumping to a new idea without a bridge
- switching examples too quickly
- starting a section with background instead of the point
- hiding the main claim inside a joke

## Repetition Rules

Repeat important ideas without sounding like a textbook.

Use:

- the same main metaphor at least 3 times
- one repeated phrase
- visible keywords on screen
- short callbacks to earlier jokes

Example:

```text
The price moved.
It moved from your wallet to your attention.
And once the price moves, it becomes much harder to see.
```

## Joke Clarity Rules

A joke is learner-friendly when:

- the setup is visible
- the punchline uses common words
- the image explains the meaning
- missing the joke does not break the section

Avoid jokes based mainly on:

- obscure slang
- old memes
- local cultural references
- fast pronunciation tricks
- heavy sarcasm with no visual clue

If using an idiom, make the context explain it.

Better:

```text
The deal has a catch. A catch is the small bad part hiding inside the good part. Modern life is mostly catches wearing nice shoes.
```

## On-Screen Learner Support

Each video should include 3 to 5 useful phrases or keywords as natural labels.

Good label types:

- `hidden cost`
- `attention inventory`
- `monthly leak`
- `the real price`
- `sounds free`
- `not the customer`

Rules:

- Keep labels short.
- Put labels near the thing they explain.
- Repeat the most important phrase.
- Do not turn the screen into a vocabulary lesson.
- Use handwritten corrections and cross-outs for clarity and humor.

## Read-Aloud Check

Read the script aloud with David23 pacing in mind.

Check:

```text
Can I say this without rushing?
Can I pause after the joke?
Can the viewer understand the sentence on first listen?
Does any paragraph sound like an essay?
Does any joke need a footnote?
```

If a line is hard to say, rewrite it.
If a line is easy to read but hard to hear, rewrite it.

## Final Gate

A script is ready for production only if:

- an intermediate English learner can follow the main argument
- the hook creates tension within 10 seconds
- no section feels like generic educational content
- every major section has a visual joke
- the repeated metaphor appears at least 3 times
- the final insight feels bigger than the topic
- the script sounds spoken, not written

If the script fails this gate, do another script pass before voiceover.
