# Deadpan Explainer Template

Classification: `Core`

Scope: `CHANNEL_WIDE`

Use this template for future `Why It Works` scripts.

The goal is a clear explainer with a dry creator voice, simple English, and one funny image per major section.

## Script Brief

```text

_____

One question the video answers:
Why _____?

_____

Main metaphor:

Repeated phrase:
_____

_____

Final bigger insight:
This is not only about _____.
It is about _____.
```

## Full Script Template

### 0. Hook

Goal:
create tension within 10 seconds.

```text
Here is something weird about _____:
_____.

That sounds normal, because modern life has trained us badly.
But if you look at it for more than three seconds, it becomes suspicious.
```

Hook checks:

- Opens with the contradiction, not background.
- Uses a concrete daily-life example.
- Gives WIT something to react to immediately.
- Has one phrase that can become a title-card label.

```text

```

### 1. Reframe

Goal:
tell the viewer what the video is really about.

```text
Most people think this is about _____.
It is not.

It is really about _____.

And once you see that, _____ starts to look less like a normal thing and more like _____.
```

### 4. Fake-Serious Beat

Use once per script when the topic needs a dry pause.

```text
This is a very advanced system called:
_____.

Scientists also refer to it as:
_____.
```

Rule:
the first name can sound official. The second name should be painfully plain.

### 5. Absurd Comparison

Use once per script to make the hidden system physical.

```text
This is basically like _____,
except _____,
and somehow everyone calls it convenient.
```

Visual note:

```text
Absurd object or scene:
_____

WIT reaction:
_____
```

### 6. Payoff

Goal:
make the final insight feel bigger than the topic.

```text
So the real reason _____ is not just _____.

It is that _____.

The system works because _____.
And the annoying part is, once you understand it, it starts appearing everywhere.
```

Payoff checks:

- Returns to the hook.
- Uses the repeated phrase one last time.
- Shows the main metaphor again.
- Gives the viewer a clean insight, not only a joke.

### 7. Outro

Keep it short.

```text
That is why _____ works.

If modern life keeps inventing normal things that are secretly ridiculous,
we will keep explaining them.
```
