# Section Joke Builder

Classification: `Core`

Scope: `CHANNEL_WIDE`

Use this builder when a future script section is correct but not funny yet.

The goal is not to add random jokes.
The goal is to make the explanation visible, concrete, and dry.

## One-Section Rule

Every major section needs:

```text
One clear point.
One funny image.
One screen phrase.
One WIT action.
One bridge to the next section.
```

If any item is missing, the section is unfinished.

## Joke Sources

Pick one primary joke source per section.

### 1. Hidden Cost

Use when something looks free, easy, cheap, or harmless.

Prompt:

```text
What is the invisible cost, and how can it hit WIT physically?
```

Example shape:

```text
It is free in the same way a door is free after you give it your house key.
```

### 2. Fake Official Language

Use when a silly behavior can be described like a serious system.

Prompt:

```text
What would this be called if a consultant wanted money for naming it?
```

Example shape:

```text
This is called `behavior optimization`, which is a nice way to say `the button is bullying you`.
```

### 3. Literal Metaphor

Use when the idea is abstract.

Prompt:

```text
If this idea became a machine, shelf, receipt, box, trap, or office, what would it look like?
```

Example shape:

```text
Your attention becomes a tiny product on a shelf.
```

### 4. Tiny Human Problem

Use when the topic is big but the viewer needs a daily-life anchor.

Prompt:

```text
What is the smallest normal moment where the viewer feels this problem?
```

Example shape:

```text
You opened the app to check one message. Now it is Tuesday.
```

### 5. Dry Correction

Use after a formal explanation that feels too clean.

Prompt:

```text
What is the blunt version of what I just said?
```

Example shape:

```text
In other words, the app did not improve your life. It improved its graph.
```

### 6. System As Character

Use when the script needs a simple antagonist.

Prompt:

```text
If the system could talk, what would it calmly say while making the problem worse?
```

Example shape:

```text
The subscription says, `Do not worry. I am small. That is how I travel in groups.`
```

## Deadpan Rewrite Recipes

### Recipe A: Abstract To Physical

```text
Abstract:
Companies monetize user engagement.

Physical:
Every extra minute you spend here becomes a tiny product with a price tag.
```

Steps:

1. Find the abstract noun.
2. Turn it into an object.
3. Put the object near WIT.
4. Give it a label.
5. Let the narrator describe it calmly.

### Recipe B: Polite To Suspicious

```text
Polite:
The platform encourages repeat usage.

Suspicious:
The platform gently invites you back, the way a trap gently invites a foot.
```

Steps:

1. Find the polite verb.
2. Ask what it really does.
3. Make the polite version sound suspicious.
4. Keep the sentence short.

### Recipe C: Explanation To Fake Term

```text
Explanation:
People spend money because the payment feels small.

Fake term:
This is called `tiny payment blindness`, also known as `oops, where did the money go`.
```

Steps:

1. Name the behavior like a serious concept.
2. Immediately translate it into plain human language.
3. Use the plain version as the joke.

### Recipe D: Data To Human Pain

```text
Data:
Retention increases ad impressions.

Human pain:
The longer WIT stays, the more ads can line up outside his brain.
```

Steps:

1. Identify the metric.
2. Identify the human feeling.
3. Put the metric in a ridiculous physical place.
4. Make WIT react silently.

## Visual Joke Patterns

Use these patterns with WIT and handwritten labels.

| Pattern | Best For | Example Visual |
|---|---|---|
| Label betrayal | hidden costs | `FREE` label peels off and reveals `paid with attention` |
| Tiny monster | small recurring charges | little bills crawling toward WIT |
| Fake machine | abstract systems | `convenience machine` takes money and prints stress |
| Shelf metaphor | attention, data, habits | WIT sits on a shelf labeled `inventory` |
| Receipt attack | money topics | receipt keeps printing until it wraps around WIT |
| Button bullying | app behavior | a button follows WIT around saying `continue` |
| Official stamp | fake-serious lines | stamp says `NORMAL ADULT PROBLEM` |
| Cross-out joke | correction beats | `helpful` crossed out, replaced with `profitable` |

## When To Cut A Joke

Cut the joke if:

- it needs too much explanation
- it requires obscure native-speaker context
- it distracts from the main point
- it cannot become a visual
- it makes WIT decorative instead of useful
- it sounds clever but not true

Keep the joke if:

- it makes the system clearer
- it gives the section a memorable image
- it can be understood from context
- it makes the viewer feel seen
- it works as a pause-frame visual

## Final Test

Read the section aloud.

Then answer:

```text
If I muted the video and looked at the frame, would I still understand the joke?
If I removed the joke, would the explanation still make sense?
If both answers are yes, the section is probably strong.
```
