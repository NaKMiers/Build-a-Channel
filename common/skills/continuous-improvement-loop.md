# Continuous Improvement Loop

The core of this workspace is continuous improvement.

Every video should improve:

- scripts
- hooks
- titles
- thumbnails
- visual systems
- voiceover
- production speed
- audience understanding

## After Each Video

Update the video's:

```text
video-projects/<slug>/06-review.md
```

Capture:

- what worked
- what felt weak
- viewer signals
- production bottlenecks
- improvements for next time

Then update:

- `docs/learning-log.md` for reusable lessons
- `common/skills/` if the workflow changed
- `common/templates/` if the template should improve
- `common/tools/` if a tool should become reusable

## Rule

Do not let lessons stay only in chat.

If a lesson can make the next video better, write it down.
