# Local Project Skills

This folder stores project-local repeatable workflows for `Why It Works`.

These are not necessarily installed Codex skills.
They are local instructions future sessions can read and follow.

## Skill Rules

- A skill should describe a repeatable workflow.
- It should be short enough to use during production.
- If a lesson improves multiple future videos, update the relevant skill.
- If a lesson only applies to one video, keep it in that video's `06-review.md`.
