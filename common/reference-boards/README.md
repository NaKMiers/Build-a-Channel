# Reference Boards

Classification: `Core`

Scope: `CHANNEL_WIDE`

This folder stores the reusable reference-board system and templates for future `Why It Works` videos.

Use the main system first:

- [Reference Board System](../reference-board-system.md)

## What Belongs Here

Use this folder for:

- reusable reference-board templates
- channel-wide board rules
- category instructions
- source-note patterns
- future shared reference-board helpers

Do not use this folder for:

- a reference board for an existing video
- topic-specific images
- one-off screenshots
- final production assets for a single video
- copied frames from other creators

## Template

Copy this folder only when a future video is explicitly allowed:

```text
common/reference-boards/_template/
```

Template folders:

```text
thumbnails/
real-life/
ui-mockups/
visual-metaphors/
wit-emotions/
color-contrast/
source-notes/
```

Future video-specific boards belong in:

```text
video-projects/<slug>/
```

only after the user says:

```text
Apply this channel-wide system to video-projects/<slug>
```

## Default Board Categories

Each future video board should collect:

- `5` real-life object references
- `5` UI, paper, or screenshot references
- `5` visual metaphor references
- `5` thumbnail tension references
- `5` WIT emotion references
- `3` color and contrast references

Target:

```text
20-30 useful references
```

## Source-Note Standard

Every saved, generated, or production-influencing reference needs a source note.

Allowed usage labels:

- `safe asset`
- `mockup target`
- `inspiration only`
- `reject`

Default decision:

```text
inspiration only
```

Promote to `safe asset` only after permission, privacy, copyright, logo, watermark, and production-use checks pass.

Use [common/assets/source-note-template.md](../assets/source-note-template.md) for any reference that becomes a reusable asset or production asset.

## Board Readiness Gate

A board is ready when it gives the future video:

- a clear thumbnail direction
- a concrete first `10` seconds idea
- at least `5` visual jokes
- one recurring motif
- recognizable real-life texture
- clean source notes
- no copied final layouts from other creators

If it does not help the video become more specific, it is not a useful board.
