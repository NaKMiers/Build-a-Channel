# Internet Trap Comedy Assets

Classification: `Core`

Scope: `CHANNEL_WIDE`

Use this category for apps, feeds, notifications, comments, online advice, install prompts, productivity content, gurus, and algorithm pressure.

## Category Rule

`The internet object should look small, but act powerful.`

## Seed Targets

| Asset ID | Object | Intended format | Safe-use target | Comedy job |
| --- | --- | --- | --- | --- |
| `internet-trap-angry-phone` | angry phone | transparent PNG or SVG | thumbnail and video | phone acts like WIT's manager |
| `internet-trap-notification-bubble` | notification bubble | transparent PNG or SVG | video-only | tiny bubble pulls attention like a hook |
| `internet-trap-infinite-feed-strip` | infinite feed strip | PNG, SVG, or HTML mockup | thumbnail and video | feed becomes a conveyor belt |
| `internet-trap-terms-scroll` | terms and conditions scroll | PNG or SVG | video-only | unread text becomes a trap door |
| `internet-trap-guru-thumbnail-frame` | fake guru thumbnail frame | fictional UI mockup | thumbnail and video | fake certainty looks more polished than reality |

## Good Uses

- make the phone or notification behave like it has a job
- use repeated copies to show attention pressure
- keep fake UI fictional and generic
- use WIT as the person being pulled, judged, or trapped

## Do Not Use For

- exact copies of real app screens
- real creator thumbnails unless clearly used as documented reference only
- real usernames, comments, or private data
- jokes that require obscure internet slang to understand
