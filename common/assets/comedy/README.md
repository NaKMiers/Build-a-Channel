# Comedy Asset Library

Classification: `Core`

Scope: `CHANNEL_WIDE`

This folder stores reusable funny visual objects, rough props, reactions, red markup pieces, and running motifs for future `Why It Works` videos.

Use this library to make boards feel more specific, lived-in, and funny when paused without rebuilding the visual language from zero for every topic.

Core rule:

`Comedy assets should make the explanation clearer, not just busier.`

## Asset Standard

Reusable comedy assets should be:

- useful across more than one future video
- readable inside a `1920x1080` board
- understandable at mobile thumbnail size if marked thumbnail-safe
- rough enough to feel human, not corporate
- simple enough to recolor, label, or combine with handwritten captions
- safe for public video use with a source note
- free of real private data, watermarks, and unclear brand logos

Prefer:

- self-made rough drawings
- generated generic objects with prompt notes
- fictional UI mockups
- self-shot or licensed objects with clean rights
- reusable transparent PNG, SVG, or web-ready assets

Avoid:

- generic icon-pack assets as the main joke
- glossy stock images that feel like ads
- real app screens copied pixel-for-pixel
- real company logos as default reusable assets
- high-detail generated images that become unreadable in motion
- one-video jokes that are not strong enough to become recurring motifs

## Category Rules

### Hidden Payment

Use for money, subscriptions, free trials, convenience fees, confusing prices, checkout pain, and adult bills.

Good jobs:

- reveal the real cost behind a friendly promise
- turn `FREE` into delayed payment
- show a small price becoming a large consequence
- make WIT physically attacked by receipts, fees, or bills

Default humor patterns:

- hidden thing revealed behind clean thing
- impossible receipt
- suspicious asterisk
- real object with stupid label

### Internet Traps

Use for social media, apps, productivity content, notifications, online advice, install prompts, and algorithm systems.

Good jobs:

- make the phone behave like a boss
- make notifications pull WIT's attention
- show feeds as conveyor belts
- turn streaks, modals, and comments into pressure objects

Default humor patterns:

- object behaving like a person
- progress bar of bad decisions
- too-clean marketing label
- fake diagram

### Modern Life Pain

Use for work, stress, delivery, cheap products, adult chores, calendar pressure, admin tasks, and lifestyle fatigue.

Good jobs:

- make normal life look like a small machine built to annoy people
- bury WIT under admin or chores
- show convenience as physically heavy
- turn checklists, calendars, and emails into visual pressure

Default humor patterns:

- list that gets more absurd
- before/after contradiction
- WIT physically suffering
- real object with stupid label

### Red Markup

Use for corrections, suspicion, punchlines, hidden terms, and dry commentary.

Good jobs:

- correct the viewer's first assumption
- expose hidden business logic
- convert clean marketing language into blunt reality
- add one final joke layer after narration lands

Default humor patterns:

- red cross-out
- bad arrow
- suspicious asterisk
- tiny legal footnote

Usage limit:

Use one dominant red-markup action per board. Too much red markup turns every frame into noise.

### WIT Props

Use when WIT should interact with the idea instead of standing near it.

Good jobs:

- give WIT a reason to be in the frame
- make WIT the scale reference for absurd systems
- let WIT point at, carry, hide from, or be trapped by the object
- turn abstract costs into physical objects

Default humor patterns:

- WIT physically suffering
- object behaving like a person
- hidden thing revealed behind clean thing
- fake diagram

## First-Pass Library Rule

Start future videos by choosing:

- `1` main recurring motif
- `2-4` supporting comedy objects
- `1` red markup style
- `1-2` WIT props

Do not throw the whole library into one video.

## Promotion Gate

An asset can move from `draft` to `usable` only after it passes:

- source note exists
- no private data or unclear logos
- safe-use decision is `approved` or `approved with limits`
- readable in a `1920x1080` mock board
- readable at thumbnail size if marked thumbnail-safe
- supports at least two likely future topics
- has one clear comedy job

If an asset only works for one specific video, keep it out of this reusable library.
