# Shared Assets

Use this folder for assets shared across many videos.

Examples:

- channel logo files
- reusable Wit reference poses
- shared background textures
- sound beds
- sound effects
- reusable icons
- thumbnail layout references
- reusable real-life objects and paper textures
- reusable fictional UI mockups
- reusable comedy objects, red markup, and WIT interaction props

Channel-wide real-life visual system:

- [real-life-visual-asset-system.md](../real-life-visual-asset-system.md)
- [real-life](real-life)
- [ui-mockups](ui-mockups)
- [source-note-template.md](source-note-template.md)

Channel-wide comedy asset system:

- [comedy](comedy)
- [comedy asset inventory](comedy/asset-inventory.md)
- [comedy source-note template](comedy/source-note-template.md)

Do not put one-off video assets here.
One-off assets belong in:

```text
video-projects/<slug>/assets/
```
