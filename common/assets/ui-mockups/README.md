# UI Mockup Asset Library

Classification: `Core`

Scope: `CHANNEL_WIDE`

This folder stores reusable fictional UI assets for future `Why It Works` videos.

Use it for fake screens that explain apps, websites, payments, subscriptions, feeds, notifications, comments, profiles, and checkout flows without relying on real screenshots.

## Mockup Rules

- Make UI fictional by default.
- Use fake names, fake balances, fake comments, and fake apps.
- Do not copy a real app screen pixel-for-pixel.
- Do not include real private account data.
- Avoid real logos unless there is a specific approved reason.
- Keep text large enough to read on mobile when it matters.
- Add handwritten labels in the video layer, not baked into every mockup, when possible.

## Safe Defaults

Prefer generic labels such as:

- `Free Plan`
- `Upgrade`
- `Monthly Bill`
- `Attention`
- `Convenience Fee`
- `Your Data`
- `Renewal Tomorrow`
- `Recommended For You`

Avoid naming real companies unless the future video explicitly requires it and has a source/rights/accuracy plan.
