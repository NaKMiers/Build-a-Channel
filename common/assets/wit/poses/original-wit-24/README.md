# Original WIT 24 Pose Set

Classification: `Core channel asset`

Scope: `CHANNEL_WIDE`

This folder is the current reusable WIT pose set for future `Why It Works` videos.

It replaces the older `core-24` and `comedy-core` folders as the default WIT source.

## Reference

Source identity: `original-wit`
