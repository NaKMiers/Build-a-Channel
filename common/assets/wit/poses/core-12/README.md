## Source Files

The `*-chroma.png` files are the original generated images with green chroma-key backgrounds.

Keep them for now because they are useful if the transparency needs to be reprocessed.

## Notes

- These assets were generated from the current WIT v3 cute-short reference direction.
- Backgrounds were removed locally into alpha PNGs.
- This is a first-pass production set, not a locked final character model sheet.
- The poses are ready for HyperFrames testing with lightweight motion: pop-in, bounce, shake, slide, scale, and simple mouth/eye overlays.

## Current Caveat

The pose set is visually consistent enough for prototype use, but it should be tested inside the first full rough cut before creating the larger Expansion 24 set.
