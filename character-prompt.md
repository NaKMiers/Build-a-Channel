Create a clean character reference sheet for ONE simple hand-drawn 2D doodle cartoon character.

REFERENCE LAYOUT:
Follow this exact sheet layout:

- Use a wide 16:9 landscape canvas (horizontal animation-model-sheet proportion), never a square canvas.
- Canvas split into a large top-left block, a top-right block, a bottom-left block, and a bottom-right prop block.
- Top-left: 3 full-body turnaround panels, left to right: front view, true side view, back view.
- Top-right: first row has 3 head-turnaround close-ups: front, three-quarter, side. Second row has 4 face-only expression panels.
- Bottom-left: 4 full-body expression/pose panels, left to right: tired hunched/slumped; strained with gritted teeth while lifting/working with a hoe; anxious with worried brows; blank/resigned.
- Bottom-right: oversized close-up of the signature prop: one simple wooden hoe and one single stalk of wheat.
- Draw visible but subtle, straight pale-grey panel-divider lines (#D9D9D9, 1–2 px) to separate EVERY panel. Add a vertical divider between the top-left and top-right blocks, a horizontal divider between top and bottom rows, and a vertical divider between the bottom-left and bottom-right blocks.
- Inside the top-left block, add TWO pale-grey vertical divider lines so the front, side, and back turnaround views each occupy their own equal-width panel; this section must not be left open or undivided.
- Inside the top-right expression row, add THREE pale-grey vertical divider lines to create four equal expression panels. Inside the bottom-left pose row, add THREE pale-grey vertical divider lines to create four equal pose panels.
- Use a very subtle, thin light-grey square grid on the pure white background, behind all characters and dividers.
- No text, labels, captions, numbers, arrows, or watermark.

One exact same early-Neolithic farmer in every panel: simple stick-figure-style doodle, large perfectly round head, tiny dot eyes, thick expressive black marker brows, very simple mouth, tiny sparse hair tuft, gaunt thin body, stooped/worn posture, plain ragged tunic, bare feet. Tunic color is dull earth-brown #8B5E3C.

CONSISTENCY:
Every panel shows the identical character design: same round head silhouette, eye spacing, eyebrows, facial proportions, body proportions, tunic, color palette, and bold outline weight. STYLE:
Extremely simple hand-drawn 2D doodle cartoon. Bold black marker outlines, slightly imperfect sketchy lines, flat solid fills only, ample clean whitespace, highly readable character-sheet presentation.

No realism, photorealism, 3D, gradients, shadows, texture, anime, detailed anatomy, extra limbs, detailed fingers, busy background, text, labels, numbers, watermark, or inconsistent character design.
