# Topic Angle Selection System

Classification: `Core`

Scope: `CHANNEL_WIDE`

Purpose:
turn broad topic ideas into sharp `Why It Works` video premises before research, packaging, scripting, or production begins.

This system is reusable. It must not be filled out for an existing video unless the user explicitly asks to apply the channel-wide system to that video project.

## Core Rule

```text
Do not choose a topic. Choose an angle.
```

A strong future video starts as:

```text
topic + contradiction + visual metaphor + viewer pain
```

The topic names the area.
The angle names why this channel should make the video now.

## Why This Exists

Broad topics can sound useful and still become weak YouTube videos.

Weak broad topic:

```text
How free apps make money.
```

Sharper angle:

```text
A helpful app is secretly a checkout that waits until you are comfortable.
```

The sharper version creates:

- a visual object
- a joke position
- a WIT emotion
- a thumbnail problem
- a reason to keep watching
- a final insight

## Good Angle Shape

Use this sentence test:

```text
This video is about how _____ looks like _____, but is actually _____.
```

Examples:

- `A helpful system looks free, but is actually a delayed checkout.`
- `A personal habit looks like discipline, but is actually a business model.`
- `A cheap product looks affordable, but is sometimes an expensive product with the future removed.`
- `A convenience tool looks friendly, but is often a fee machine wearing a friendly jacket.`
- `A productivity promise looks like control, but may only sell the feeling of control.`

## Required Inputs

Start each topic selection pass with `5-10` raw topic ideas.

For each raw idea, write:

```text
Raw topic:
Viewer pain:
Hidden system:
Contradiction:
Possible visual metaphor:
Why English learners would care:
```

Do not move to scripting from a raw topic alone.

## What Each Field Must Do

`Topic`
The broad subject area. Keep it plain.

`Sharp angle`
The authored point of view. This should sound like a `Why It Works` video, not a textbook chapter.

`Main contradiction`
The tension that makes the viewer ask `wait, why?`

`Recurring metaphor`
The repeated image that can carry the explanation across scenes.

`Thumbnail tension`
The tiny visual problem: one object, one contradiction, one WIT emotion.

`First 10 seconds`
A situation, not an introduction. It should show the topic by second `3`, the contradiction by second `5`, WIT's emotion by second `8`, and the bigger question by second `10`.

`WIT role`
What the system does to WIT. Avoid neutral presenter WIT.

`Real-life objects`
Objects, UI mockups, receipts, bills, phones, papers, products, feeds, boxes, or other evidence that make the angle feel lived-in.

`Final insight`
The useful thing the viewer understands by the end.

`Why now`
The current relevance or viewer pressure.

`Why this channel`
Why this belongs to `Why It Works`: money, internet, society, business, modern life, simple English, dry humor, learner-friendly clarity.

## Workflow

1. Collect `5-10` raw topic ideas.
2. Convert each raw topic into `1-3` possible angles.
3. Remove any angle that violates the rejection rules below.
4. Score the strongest angle for each topic with [topic-angle-scorecard.md](topic-angle-scorecard.md).
5. Keep only angles scoring `30/40` or higher for normal long-form production.
6. Pick the best `1-2` candidates.
7. Build rough title and thumbnail tension before scripting.
8. Write the first `10` seconds before expanding into a full script.
9. Move into reference-board research only after the angle passes.

## Production Threshold

For normal long-form videos:

```text
Minimum score: 30 / 40
No critical category below 3 / 5
No hard-fail rejection rule triggered
```

Critical categories:

- `Curiosity`
- `Visual motif`
- `Explanation depth`
- `Packaging strength`

If a candidate scores below `30/40`, do not produce it as a normal long video.

Possible exceptions:

- label it clearly as an `Experiment`
- use it as a short-form test
- revise the angle and rescore
- get explicit user approval to make a lower-score video anyway

## Rejection Rules

Reject or revise an angle if:

- it sounds like generic education
- it is only advice, motivation, or opinion
- the thumbnail would be mostly text
- there is no repeated visual metaphor
- WIT has no reason to appear
- WIT would only stand beside text as a presenter
- there is no real-life object or evidence
- the joke exists only in the script and not on screen
- the final insight is obvious
- the explanation has no real system behind it
- it needs a dense native-English cultural reference to work
- it does not help English learners understand modern life
- it is rage bait, fake-deep, or misleading
- it requires production assets the channel cannot make safely

## Acceptance Criteria

An angle is ready when:

- it can be explained in one sentence
- it creates a thumbnail image immediately
- it gives WIT a clear emotional role
- it has a repeated visual motif
- it supports at least `5` visual jokes
- it has at least `3` real-life object or UI evidence options
- it can produce a first `10` seconds hook without definitions
- it ends with a useful insight
- it fits simple, funny English for intermediate learners
