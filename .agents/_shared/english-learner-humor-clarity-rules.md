# English Learner Humor Clarity Rules

Classification: `Core`

Scope: `CHANNEL_WIDE`

Purpose:
keep `Why It Works` funny, dry, and rough without making jokes too hard for English learners to decode.

This file applies to future scripts, visual boards, WIT reactions, voice tests, rough cuts, and final reviews.

## Core Rule

`Make the joke visible before making it clever.`

The explanation should survive even if the viewer misses the joke.

## Best Joke Sources

Use jokes that come from:

- visible contradiction
- simple real-life pain
- WIT's obvious emotion
- fake-serious labels
- red corrections
- repeated phrases with a twist
- a normal object becoming suspicious
- an invisible system becoming a physical thing

Good joke pattern:

```text
Explanation:
The app makes entry easy, then makes leaving annoying.

Visual:
WIT enters a door labeled EASY ENTRY. The exit is a tiny maze labeled CANCEL PLAN.
```

The joke works because the situation is visible.

## Risky Joke Sources

Use carefully:

- pure wordplay
- heavy sarcasm
- slang-heavy punchlines
- niche US/UK cultural references
- memes that need prior knowledge
- jokes where the literal sentence says the opposite of the point
- long setups that delay the explanation

Hard fail:
a learner must know the reference before they can understand the main point.

## Sarcasm Rules

Sarcasm can work if the visual makes the real meaning obvious.

Safer:

```text
Voice:
Great. Another free app.

Visual:
WIT stands under a giant receipt labeled FREE.
```

Risky:

```text
Voice:
Oh yeah, because companies famously love giving away money.
```

Why risky:
the literal meaning is the opposite of the real meaning, and the joke depends on tone.

If sarcasm carries an important point, add one of these:

- visible contradiction
- WIT reaction
- red correction
- immediate plain sentence

## Wordplay Rules

Wordplay is optional.

Use wordplay only when:

- the point is already clear
- the pun is simple
- the visual supports it
- missing the wordplay does not break the section

Avoid wordplay when:

- the phrase is uncommon
- pronunciation matters too much
- the joke hides a key term
- the viewer must know two meanings of a word to follow the explanation

## Cultural Reference Rules

Cultural references should be bonus texture, not the load-bearing wall.

Before using a reference, ask:

```text
Would the joke still work if the viewer has never seen this meme, movie, app trend, or internet drama?
```

If not, replace it with:

- a daily-life object
- a fake diagram
- WIT suffering
- a simple analogy
- a direct visual contradiction

## WIT Humor Rules

WIT makes learner-friendly humor easier because emotion is visible.

Strong WIT jokes:

- WIT trusts the system and immediately regrets it
- WIT follows a simple label into a worse situation
- WIT silently reacts while the narrator stays calm
- WIT is physically affected by an invisible cost
- WIT points at the exact word or object that makes the joke clear

Weak WIT jokes:

- WIT stands beside text with no role
- WIT does a random funny pose unrelated to the point
- WIT explains the joke like a teacher
- WIT's emotion conflicts with the narration

## Red Markup Rules

Red markup is learner-friendly when it shows the correction.

Use red markup for:

- crossing out false labels
- revealing hidden costs
- circling the suspicious part
- adding a dry correction
- changing a polite phrase into the honest phrase

Example:

```text
Original label: FREE
Red correction: FREE*
Small note: *later, somehow
```

Avoid red markup that adds a second joke if the first joke is not clear yet.

## Joke Density Rules

Use one main joke per board.

In dense explanation sections:

- reduce joke count
- use calmer boards
- keep labels clear
- let the explanation breathe

In lighter sections:

- add small WIT reactions
- use repeated phrase twists
- use red corrections
- bring back the motif

Do not stack:

```text
slang + sarcasm + tiny label + cultural reference + fast board change
```

That is usually funny only to the editor.

## Punchline Timing Rules

For voice and boards:

- leave a beat before important punchlines
- show the punchline label on or just before the spoken cue
- keep the label visible after the line lands
- let silence or near-silence carry some jokes
- do not cover punchline words with sound effects

If a joke needs speed to work, test whether it still works at learner-friendly pacing.

## Humor Review Questions

For each major joke, ask:

```text
What is the point?
What is the visible situation?
What does WIT feel?
Can the joke be understood without native slang?
Does the joke make the explanation clearer?
Would the section still make sense if the joke is missed?
```

If the joke fails two or more questions, simplify it.

## Pass Standard

Humor clarity passes when:

- the joke comes from context
- the visual explains the emotional meaning
- WIT has a clear reason to react
- sarcasm is not carrying the whole explanation
- slang and references are optional
- the main point remains understandable without the joke

## Hard Fails

Reject jokes that:

- require deep native cultural knowledge
- hide the main point behind irony
- force the narrator to speak too fast
- need a long explanation after the punchline
- make the viewer feel stupid for not getting the reference
- are funny in text but impossible to show clearly
