# Real-Life Asset Library

Classification: `Core`

Scope: `CHANNEL_WIDE`

This folder stores reusable real-life or real-looking assets for future `Why It Works` videos.

Use it for generic objects, paper textures, receipt and bill patterns, physical contexts, and cutouts that can support multiple videos.

Do not store one-off video assets here.

## Folder Map

```text

  self-shot/
  generated/
  public-domain-licensed/
  paper-textures/
  receipts-and-bills/
  object-cutouts/

```

## Category Jobs

| Folder | Job |
| --- | --- |
| `self-shot/` | original photos shot by Anh Khoa or the production team |
| `generated/` | AI-generated generic real-life objects or scenes |
| `public-domain-licensed/` | external assets with documented safe rights |
| `paper-textures/` | scanned or generated paper, notes, receipts, bills, checklists |
| `receipts-and-bills/` | generic fake receipts, bills, invoices, subscription papers |
| `object-cutouts/` | transparent or cutout-ready objects such as phones, cards, bags, boxes |
| `physical-context/` | desks, rooms, delivery bags, moving boxes, work setups, clutter |
| `source-notes/` | source notes when not kept beside individual assets |

## Rules

- Keep assets generic enough for multiple videos.
- Remove or replace all private information.
- Avoid real brand logos unless there is a documented reason.
- Add a source note using [source-note-template.md](../source-note-template.md).
- Use lowercase kebab-case filenames.
- Prefer imperfect lived-in texture over glossy stock-photo polish.

## Reusable Asset Standard

An asset is reusable only if:

- it can support more than one future video
- it has a clear source note
- it has no private data
- it is safe for public video use
- it works at `1920x1080`
- it can still communicate at mobile scale when it carries meaning

See [real-life-visual-asset-system.md](../../real-life-visual-asset-system.md) for the full channel-wide rules.
