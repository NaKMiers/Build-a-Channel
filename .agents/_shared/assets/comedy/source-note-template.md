# Comedy Asset Source Note Template

Classification: `Core`

Scope: `CHANNEL_WIDE`

Use this template for reusable comedy assets under `.agents/_shared/assets/comedy/`.

Keep the source note beside the asset when possible:

```text
asset-name.png
asset-name.source.md
```

If many assets are generated in one batch, a category-level source note can live in the category folder, but each asset still needs a clear asset ID and safe-use decision.

## Required Checks

Before marking `approved`, confirm:

- no private data is visible
- no watermark is visible
- no unclear brand logo is visible
- source and rights are documented
- generated assets include prompt/tool/date notes
- text baked into the asset is readable or intentionally minimal
- the asset supports more than one future topic
- the asset fits the channel tone: smart, simple, funny, dry

Do not use assets marked `unclear`, `needs review`, or `reference only` in public video output.
