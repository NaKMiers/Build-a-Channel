# Red Markup Comedy Assets

Classification: `Core`

Scope: `CHANNEL_WIDE`

Use this category for correction beats, suspicion, reveals, fake footnotes, punchlines, and dry commentary.

## Category Rule

`Red markup is the channel's annoyed editor.`

## Seed Targets

| Asset ID | Object | Intended format | Safe-use target | Comedy job |
| --- | --- | --- | --- | --- |
| `red-markup-cross-out` | red cross-out | transparent PNG or SVG | thumbnail and video | cancels the polite version |
| `red-markup-rough-circle` | rough circle | transparent PNG or SVG | video-only | circles the ignored suspicious detail |
| `red-markup-warning-arrow` | warning arrow | transparent PNG or SVG | thumbnail and video | points too aggressively at the real problem |
| `red-markup-footnote-star` | fake footnote star | transparent PNG, SVG, or text style | thumbnail and video | adds tiny legal betrayal |
| `red-markup-nope-stamp` | `NOPE` stamp | transparent PNG or SVG | video-only | rejects a bad assumption without explaining too much |

## Good Uses

- add after the narration sets up the clean version
- keep the mark rough, fast, and human
- use one dominant red action per board
- make the red mark point to the exact hidden mechanism

## Do Not Use For

- every board in the same way
- marks that cover important readable text
- decorative red accents with no correction job
- complex footnotes that English learners cannot read quickly
