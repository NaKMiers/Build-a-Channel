# Comedy Asset Inventory

Classification: `Core`

Scope: `CHANNEL_WIDE`

This inventory tracks reusable comedy asset targets for `Why It Works`.

Status values:

- `target`: approved reusable idea, asset file not created yet
- `draft`: rough asset exists but needs source/readability review
- `usable`: approved for reusable channel use
- `reference-only`: useful for inspiration but not a production asset
- `reject`: do not use

Safe-use values:

- `thumbnail`: safe for thumbnails and video
- `video-only`: safe inside videos, not strong or readable enough for thumbnails
- `reference-only`: do not use directly in public output
- `needs-review`: no production use until source/readability checks pass

## Current Library Status

This first pass defines the reusable comedy library structure and seed inventory.

No binary visual asset is promoted to `usable` until a source note and readability test exist.

## Readability Tests

Before promoting a target to `usable`, test it in:

- a `1920x1080` board with WIT or handwritten label nearby
- a thumbnail-size preview around `320x180`
- a paused-frame check with no narration context

Promotion question:

`Can an English learner understand what this object is and why it is funny without reading a long sentence?`
