# WIT Prop Comedy Assets

Classification: `Core`

Scope: `CHANNEL_WIDE`

Use this category for reusable props WIT can hold, carry, point at, hide behind, be trapped by, or suffer from.

## Category Rule

`If WIT is in the frame, the prop should give him a job.`

## Seed Targets

| Asset ID | Object | Intended format | Safe-use target | Comedy job |
| --- | --- | --- | --- | --- |
| `wit-prop-red-marker` | red marker | transparent PNG or SVG | video-only | WIT becomes the annoyed editor |
| `wit-prop-data-box` | moving box labeled `data` | transparent PNG or SVG | thumbnail and video | WIT carries the thing he did not know he sold |
| `wit-prop-fake-contract` | fake contract | transparent PNG or SVG | video-only | tiny text creates adult consequences |
| `wit-prop-calculator` | calculator | transparent PNG or SVG | video-only | simple math becomes emotional damage |
| `wit-prop-umbrella-against-bills` | tiny umbrella against bills | transparent PNG or SVG | thumbnail and video | WIT protects himself from financial weather |

## Good Uses

- pair the prop with a WIT pose that already matches the emotion
- use the prop as scale reference for the absurdity
- make WIT look affected by the system, not like a neutral presenter
- keep labels short enough to read beside the character

## Do Not Use For

- props that WIT cannot plausibly hold or react to
- props that duplicate the main object without adding a joke
- overly detailed props that fight the WIT silhouette
- video-specific references that will not recur
