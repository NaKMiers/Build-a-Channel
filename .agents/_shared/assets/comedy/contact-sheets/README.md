# Comedy Asset Contact Sheets

Classification: `Core`

Scope: `CHANNEL_WIDE`

This folder stores contact sheets for reusable comedy assets.

Use contact sheets to review whether assets are readable, funny, and safe before promoting them from `draft` to `usable`.

## Required Sheets

Create these files when each category has real assets:

```text
hidden-payment-contact-sheet.png
internet-traps-contact-sheet.png
modern-life-pain-contact-sheet.png
red-markup-contact-sheet.png
wit-props-contact-sheet.png
```

## Sheet Layout

Each contact sheet should include:

- asset preview on a light background
- asset preview on a dark or colored board background
- filename
- asset ID
- status
- safe-use target
- one short joke job
- thumbnail-size preview

## Readability Gate

Before a sheet is accepted, check:

- can the object be identified in under `1` second?
- does the silhouette survive at thumbnail size?
- is baked-in text readable or unnecessary?
- does the object still work beside WIT?
- does the asset feel rough and human, not corporate?

Assets that fail the contact sheet check stay `draft` or become `reject`.
