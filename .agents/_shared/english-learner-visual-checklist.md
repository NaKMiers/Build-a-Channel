# English Learner Visual Checklist

Classification: `Core`

Scope: `CHANNEL_WIDE`

Purpose:
make future `Why It Works` boards, rough cuts, and final renders visually clear for English learners.

This checklist is reusable. It must not be filled out for an existing video unless the user explicitly asks to apply the channel-wide system to that video project.

## Visual Decision

Use this result:

```text
PASS: visuals support learner comprehension
FIX: revise listed boards, then check again
FAIL: the cut is too hard to follow visually
```

## 1. One Thought Per Board

```text
[ ] each board has one main idea
[ ] each board has one dominant object, WIT reaction, or diagram
[ ] repeated symbols mean the same thing every time
[ ] no board asks the viewer to decode multiple jokes at once
[ ] boards change because the meaning changes, not because motion is available
```

Hard fail:
a paused frame looks active but the viewer cannot tell what it means.

## 2. Label Readability

```text
[ ] labels are short
[ ] labels use common words where possible
[ ] labels are large enough at mobile size
[ ] labels do not compete with full captions
[ ] cue-critical labels appear before or on the spoken cue
[ ] text stays visible long enough to read
```

Prefer labels like:

```text
hidden cost
not really free
easy entry
pay later
attention trap
```

Avoid:

```text
monetization strategy optimization pipeline
```

Decision:

```text
Label readability: PASS / FIX / FAIL
Required fix:
```

## 3. Visual Meaning

```text
[ ] arrows point to specific objects or words
[ ] red markup corrects, reveals, or jokes about something clear
[ ] WIT emotion is readable without narration
[ ] real-life objects explain context, not decoration
[ ] visual metaphors are simple enough to understand quickly
[ ] diagrams use few parts and obvious relationships
```

Working rule:

`If the visual is removed, the explanation should still work. If the audio is muted, the board should still hint at the point.`

## 4. Learner Timing

```text
[ ] difficult narration has slower visual changes
[ ] fast text changes do not happen during dense explanation
[ ] punchline labels have room to land
[ ] key terms stay on screen after they are spoken
[ ] there is enough time to read one short label before the board changes
[ ] subtitles, labels, and props do not fight for attention
```

Hard fail:
the viewer must choose between reading the board and hearing the explanation.

Decision:

```text
Learner timing: PASS / FIX / FAIL

```

## 5. WIT Clarity

```text
[ ] WIT has one clear emotion per board
[ ] WIT looks at, points to, suffers from, or reacts to the main idea
[ ] WIT is not used as decoration beside text
[ ] WIT does not block key labels or objects
[ ] WIT emotion supports the joke or explanation
```

Use WIT when the system needs a human target.

## Pass Standard

Visual clarity passes when:

- paused frames help the viewer recover meaning
- labels support listening instead of competing with it
- WIT's emotion is obvious
- jokes are visible from the situation
- dense ideas get calmer boards
- mobile-size viewing still works
