# Thumbnail Visual Patterns

Classification: `Core`

Scope: `CHANNEL_WIDE`

These are reusable visual patterns for future `Why It Works` thumbnails.
They are not per-video concepts.

## 1. Hidden Checkout

Use when a normal object secretly costs more than it appears.

Structure:

```text
Object looks friendly -> hidden payment point appears -> WIT looks betrayed
```

Best label style:

```text
[CLAIM]?
[PRICE]?
NOT [CLAIM]
```

Best title match:

```text
The Hidden Cost Of [normal thing]
Why [normal thing] Is Not Really [simple belief]
```

## 2. Trap Interface

Use when an app, platform, routine, or system keeps the viewer inside.

Structure:

```text
Screen or checklist becomes a box/cage -> WIT is stuck inside or pulled toward it
```

Best label style:

```text
STUCK?
WHY?
FIXED?
```

Best title match:

```text
How [normal thing] Quietly Became [weird outcome]
Why [normal thing] Keeps Getting Worse
```

## 3. Leaking Wallet

Use when the topic is about many small costs, invisible spending, or mental expense.

Structure:

```text
Wallet or bill leaks tiny repeated costs -> WIT tries to stop the leak
```

Best label style:

```text
WHERE?
BROKE?
AGAIN?
```

Best title match:

```text
Why [normal thing] Feels So [emotion/problem]
The Hidden Cost Of [normal thing]
```

## 4. Fake Bargain

Use when the promise looks good but the reality is worse.

Structure:

```text
Discount tag or shiny claim -> reveal downgrade, catch, or missing piece -> WIT looks suspicious
```

Best label style:

```text
CHEAP?
BETTER?
REALLY?
```

Best title match:

```text
Why [normal thing] Keeps Getting Worse
Why [normal thing] Is Not Really [simple belief]
```

## 5. Pressure Pile

Use when modern life creates too many small demands.

Structure:

```text
Many small objects pile onto WIT -> one label names the absurd pressure
```

Best label style:

```text
NORMAL?
WHY?
TOO MUCH
```

Best title match:

```text
Why [normal thing] Feels So [emotion/problem]
The Strange Logic Behind [normal thing]
```

## 6. Before/After Lie

Use when a claim and reality are in conflict.

Structure:

```text
Left side: promise. Right side: reality. WIT reacts from the reality side.
```

Best label style:

```text
PROMISE?
REALITY
WAIT
```

Best title match:

```text
Why [normal thing] Is Not Really [simple belief]
How [normal thing] Quietly Became [weird outcome]
```

## Pattern Selection Rule

Pick the pattern that makes the contradiction visible fastest.

Do not pick a pattern because it looks neat.
Pick the one that makes a viewer ask the strongest question.
