# Thumbnail Templates

Classification: `Core`

Scope: `CHANNEL_WIDE`

This folder stores reusable thumbnail and title templates for future `Why It Works` packaging work.

These are not final thumbnails for existing videos.
Use them only when a future video explicitly enters packaging.

## Files

- [thumbnail-brief-template.md](thumbnail-brief-template.md)
  Fill-in template for one future video's packaging brief.
- [title-thumbnail-pair-template.md](title-thumbnail-pair-template.md)
  Matrix for creating `10` titles, `5` thumbnail concepts, and one recommended pair.
- [visual-patterns.md](visual-patterns.md)
  Reusable channel-wide thumbnail concept patterns.
- [wireframes/object-left-wit-right.svg](wireframes/object-left-wit-right.svg)
  Generic 1280x720 layout for object-as-villain thumbnails.
- [wireframes/object-center-wit-corner.svg](wireframes/object-center-wit-corner.svg)
  Generic 1280x720 layout for object-dominant thumbnails.
- [wireframes/trap-around-wit.svg](wireframes/trap-around-wit.svg)
  Generic 1280x720 layout for system-trap thumbnails.

## How To Use

1. Start with [thumbnail-packaging-system.md](../thumbnail-packaging-system.md).
2. Fill [thumbnail-brief-template.md](thumbnail-brief-template.md).
3. Generate title and thumbnail options in [title-thumbnail-pair-template.md](title-thumbnail-pair-template.md).
4. Choose a visual pattern from [visual-patterns.md](visual-patterns.md).
5. Use a wireframe only as a rough composition guide.
6. Score the final pair with [packaging-scorecard.md](../packaging-scorecard.md).

Do not create per-video packaging from this folder unless the user explicitly asks to work on a specific video.
