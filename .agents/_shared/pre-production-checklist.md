# Pre-Production Checklist

Classification: `Core`

Scope: `CHANNEL_WIDE`

Purpose:
make future `Why It Works` videos prove their package, hook, motif, script, board plan, and prototype before full production starts.

This checklist is reusable. It must not be filled out for an existing video unless the user explicitly asks to apply the channel-wide system to that video project.

## Stop Rule

If a section below fails, stop at that section.

Do not move forward because the script is interesting, the topic is useful, or production has already started.

## Previous Upload Learning Gate

Use [publishing-feedback-loop.md](publishing-feedback-loop.md), [post-upload-review-template.md](post-upload-review-template.md), and [channel-learning-rules.md](channel-learning-rules.md) when a prior future upload has produced a reusable lesson.

```text
[ ] previous upload review exists, or there is no prior upload signal yet
[ ] at least one reusable lesson is named, or `No reusable lesson yet` is recorded
[ ] lesson confidence is High / Medium / Low
[ ] lesson affects a concrete choice in this video
[ ] low-confidence lesson is labeled as an experiment if used
```

Decision:

```text
Previous upload learning: PASS / FIX / NO SIGNAL
Lesson used:
Concrete change:
```

Do not invent a lesson just to satisfy the loop.
If there is no signal yet, continue with the existing channel systems.

## 0. Topic Angle Gate

Use [topic-angle-selection-system.md](topic-angle-selection-system.md) and [topic-angle-scorecard.md](topic-angle-scorecard.md) before packaging, scripting, or reference-board work.

```text
[ ] raw topic has been turned into a sharp angle
[ ] main contradiction is clear in one sentence
[ ] recurring metaphor exists
[ ] thumbnail tension is visible, not only verbal
[ ] WIT has an emotional role
[ ] at least `3` real-life objects, UI mockups, or evidence options exist
[ ] final insight is not obvious
[ ] score is `30/40` or higher
[ ] Curiosity, Visual motif, Explanation depth, and Packaging strength are each at least `3/5`
[ ] no hard-fail rejection rule is triggered
```

Decision:

```text
Topic angle: PASS / FIX / FAIL / EXPERIMENT
Score: __ / 40
Required fix:
```

Do not continue to packaging or scripting unless the topic angle passes, or the user explicitly approves it as an experiment.

## 1. Topic Fit

```text
[ ] topic fits money, internet, society, business, or modern life
[ ] topic has a clear daily-life pain, contradiction, or weird system
[ ] topic can be explained in simple English
[ ] topic is not only advice, motivation, or generic education
[ ] topic has one core question
```

Pass only if the topic creates one of these reactions:

```text
Wait, that's true.
I never thought about it like that.
This annoys me too.
I know the symptom, but not the reason.
```

## 2. Packaging Gate

```text
[ ] final or near-final title
[ ] thumbnail concept
[ ] one dominant visual object or situation
[ ] one visible contradiction
[ ] one clear WIT emotion
[ ] thumbnail label is `1-3` words
[ ] title and thumbnail do not repeat the same information
[ ] first `10` seconds can pay off the package
```

Decision:

```text
Packaging: PASS / FIX / FAIL
Required fix:
```

Do not script until packaging is at least `PASS`.

## 3. Hook Gate

```text
[ ] first `10` second board plan exists
[ ] topic appears by second `3`
[ ] contradiction appears by second `5`
[ ] WIT emotion appears by second `8`
[ ] bigger question appears by second `10`
[ ] opening is a situation, not a title card
[ ] hook can be understood without audio
[ ] hook can be read at mobile size
```

Decision:

```text
Hook: PASS / FIX / FAIL
Required fix:
```

Do not lock the script until the hook passes.

## 4. Motif Gate

```text
[ ] one recurring visual motif is chosen
[ ] motif appears in the hook or first section
[ ] motif can return naturally in at least `3` places
[ ] motif supports jokes and explanation
[ ] motif is simple enough for HyperFrames
[ ] motif does not depend on unsafe assets or copied reference material
```

Decision:

```text
Motif: PASS / FIX / FAIL
Required fix:
```

If the motif cannot repeat, it is probably only a one-off gag.

## 5. Script Gate

```text
[ ] one main metaphor
[ ] one repeated phrase
[ ] one visual joke per section
[ ] clear section structure
[ ] each section has one boardable idea
[ ] ending lands a real insight
[ ] learner-friendly clarity pass completed with [english-learner-script-checklist.md](english-learner-script-checklist.md)
[ ] useful phrase layer checked with [english-learner-useful-phrase-rules.md](english-learner-useful-phrase-rules.md)
[ ] humor clarity checked with [english-learner-humor-clarity-rules.md](english-learner-humor-clarity-rules.md)
[ ] narration markup added for pauses, beats, deadpan, slower lines, and emphasis
```

Learner-friendly pass:

```text
[ ] short sentences
[ ] common words before fancy words
[ ] useful repeated keywords
[ ] jokes work from context
[ ] no dense unexplained idioms
[ ] no classroom-style vocabulary interruption
```

Decision:

```text
Script: PASS / FIX / FAIL
Required fix:
```

Do not generate full voiceover until the script passes.

## 6. Board Plan Gate

```text
[ ] full board list exists
[ ] one thought per board
[ ] WIT role is defined per board
[ ] real-life object, mockup, paper, phone, bill, receipt, or texture is planned where useful
[ ] on-screen labels are short and readable
[ ] timing cues are tied to spoken phrases
[ ] red markup has a joke or clarity purpose
[ ] visual clarity pass completed with [english-learner-visual-checklist.md](english-learner-visual-checklist.md)
[ ] source notes are planned for non-original assets
```

Decision:

```text
Board plan: PASS / FIX / FAIL
Required fix:
```

Do not animate or render until the board plan passes.

## 7. Voice Test Gate

```text
[ ] first `45-60` seconds marked for narration
[ ] David23 test generated with the intended speed candidate
[ ] dense line tested for clarity
[ ] punchline tested for deadpan timing
[ ] voice does not outrun labels or jokes
[ ] voice remains clear for English learners
```

Decision:

```text
Voice test: PASS / FIX / FAIL
Required fix:
```

Do not generate full voiceover if the test voice makes the hook feel rushed or unclear.

## 8. Prototype Gate

```text
[ ] first `30-60` seconds rendered
[ ] thumbnail mockup reviewed beside the prototype or directly against it
[ ] voice test synced
[ ] first `10` seconds watched without audio
[ ] prototype watched at mobile size
[ ] captions or key labels are readable
[ ] WIT feels funny or useful
[ ] visuals feel human, dry, and slightly rough rather than too clean
```

Prototype must prove:

```text
[ ] click tension
[ ] hook clarity
[ ] visual identity
[ ] WIT role
[ ] voice timing
[ ] learner readability
[ ] production feasibility
```

Decision:

```text
Prototype: PASS / FIX / FAIL
Required fix:
```

Do not start full render production until the prototype passes.

## Full Production Permission

Full production may begin only when:

```text
[ ] topic angle passes
[ ] package passes
[ ] hook passes
[ ] motif passes
[ ] script passes
[ ] board plan passes
[ ] voice test passes
[ ] prototype passes
```

If the prototype is clear but boring, the video is not ready.

If the prototype is funny but unclear, the video is not ready.

If the prototype works only with audio, the hook is not ready.
