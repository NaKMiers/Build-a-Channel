# Topic, Packaging, And Hook System

Classification: `Core production system`

Scope: `CHANNEL_WIDE`

Use this file for topic intake, research framing, packaging, thumbnail planning, and first `10` seconds checks.

## Topic Angle Rule

Do not choose a topic. Choose an angle.

Each long-form candidate should be shaped as:

```text
topic + contradiction + visual metaphor + viewer pain
```

Good angles create one of these reactions:

- `Wait, that's true`
- `I never thought about it like that`
- `This annoys me too`
- `I know the symptom, but not the reason`

## Topic Angle Scorecard

Score each category from `1-5`:

- Curiosity
- Relatability
- Visual motif
- Humor potential
- English learner fit
- Explanation depth
- Packaging strength
- Production feasibility

Normal long-form threshold:

- `30/40` or higher
- no critical category below `3/5`

Critical categories:

- Curiosity
- Visual motif
- Explanation depth
- Packaging strength

Hard fails:

- generic educational topic with no contradiction
- mostly abstract or text-only visuals
- no WIT role
- weak daily-life pain
- weak first `10` seconds
- obvious final insight
- poor English learner fit

## Packaging Rule

Packaging decides the click promise before voiceover and visual production.

Title and thumbnail must work as a pair:

- Title creates the question.
- Thumbnail shows the contradiction.
- First `10` seconds pays off both.

## Thumbnail Formula

```text
one dominant object + one contradiction + one WIT emotion + 1-3 readable words
```

Strong thumbnails usually use:

- one real or real-looking object
- one visible problem
- one emotional WIT reaction
- one short label or red correction
- high contrast at small size

Avoid:

- too many objects
- fake claims
- generic shocked thumbnails
- title text copied into thumbnail text
- unclear screenshots
- real private data
- exact layouts from other creators

## Packaging Scorecard

Score package strength out of `100`:

- `15` one-second clarity
- `20` curiosity gap
- `15` visual contradiction
- `10` WIT emotion
- `15` title strength
- `10` title-thumbnail contrast
- `10` first `10` seconds promise
- `5` learner-friendly clarity

Recommended pass threshold: `75/100`.

Hard fails:

- misleading claim
- confusing visual promise
- thumbnail unreadable at mobile size
- title and thumbnail repeat the same idea
- WIT emotion does not match the topic
- first `10` seconds cannot pay off the click

## First 10 Seconds Rule

Open with a situation, not an introduction.

Default hook sequence:

```text
normal thing -> suspicious detail -> WIT reaction -> bigger question
```

Targets:

- by second `3`: show the topic
- by second `5`: show the contradiction
- by second `8`: show WIT's emotional position
- by second `10`: pay off the title-thumbnail promise

Avoid:

- branding first
- definitions first
- polite setup
- abstract explanation before the viewer sees the problem

## Four-Board Hook Template

```text
Board 1: normal everyday object or situation
Board 2: suspicious detail appears
Board 3: WIT reacts
Board 4: bigger question or contradiction
```

Each hook board needs:

- one readable label
- one clear visual job
- one spoken cue
- one reason to keep watching
