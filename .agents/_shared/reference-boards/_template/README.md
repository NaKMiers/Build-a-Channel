## Source-Note Checklist

Before a reference influences final production, confirm:

- source URL or local origin is documented
- creator or owner is noted when known
- collection date is written
- usage status is assigned
- private information is absent or fully avoided
- real logos are absent or intentionally justified
- copyrighted material is not copied into a final frame
- final use is either original, licensed, public-domain, self-made, generated safely, or recreated as a fictional mockup

## Readiness Gate

This board is ready when it can answer:

- What is the thumbnail contradiction?
- What is the first `10` seconds visual situation?
- What are at least `5` paused-frame jokes?
- What recurring object or motif returns later?
- Which references are only inspiration?
- Which assets are safe to use or need recreation?

If those answers are weak, keep researching before scripting or production.
