# Real-Life References

Use this folder for objects, paper, rooms, screens, and physical evidence connected to the topic.

Look for:

- bills
- receipts
- phones
- wallets
- packages
- checkout pages
- warning labels
- calendars
- work desks

Mark each item as `safe asset`, `mockup target`, `inspiration only`, or `reject`.

Prefer references that make the viewer think:

```text
That is my life.
```
