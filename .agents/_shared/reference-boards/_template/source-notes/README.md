# Source Notes

Every saved, generated, or production-influencing reference needs a source note.

## Short Template

```markdown
# Reference Source Note

Reference ID:

Category:

File path or URL:

Source type:
`self-shot` / `generated` / `public-domain` / `licensed` / `self-made mockup` / `recreated mockup target` / `screenshot reference` / `creator reference`

Creator/owner if known:

Date collected:

Usage status:
`safe asset` / `mockup target` / `inspiration only` / `reject`

Safe-use decision:

Production use allowed:
`yes` / `no` / `only after recreation` / `unclear`

Reason:

Notes:
```

## Default Decisions

Use `inspiration only` for references from other creators, YouTube thumbnails, copyrighted screenshots, branded UI, or unclear image sources.

Use `mockup target` when the final video should recreate the pattern as a fictional UI, fake receipt, generated object, or self-made prop.

Use `safe asset` only after source, permission, privacy, logo, watermark, and production-use checks pass.

Use `reject` when the source is unclear, privacy-sensitive, too close to another creator's frame, legally risky, or off-brand.
