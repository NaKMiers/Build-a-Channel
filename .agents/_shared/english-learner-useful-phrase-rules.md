# English Learner Useful Phrase Rules

Classification: `Core`

Scope: `CHANNEL_WIDE`

Purpose:
define how `Why It Works` uses useful English phrases as a natural layer inside entertainment-first explainers.

This file does not create vocabulary lessons. It keeps useful English visible, repeated, and memorable without interrupting the video.

## Core Rule

`Useful phrases should help the explanation before they teach English.`

The viewer should notice useful English because the phrase is doing work in the story, joke, or final insight.

## Phrase Count

Each long video may highlight:

```text
3-5 useful phrases
```

Fewer is fine.

More than `5` usually turns the video into a lesson or makes the screen too busy.

## Good Phrase Types

Use phrases that are:

- useful outside the video
- easy to repeat
- connected to the topic
- short enough for on-screen labels
- natural in spoken English
- strong enough to return later with a twist

Examples:

```text
not really free
hidden cost
easy entry
the long game
somewhere less visible
part of your day
moving house
pay later
tiny monthly leak
attention trap
```

## Bad Phrase Types

Avoid phrases that are:

- too academic
- too niche
- too slang-heavy
- only funny once
- hard to pronounce without benefit
- useful only inside one joke
- chosen because they sound like classroom vocabulary

Weak examples:

```text
monetization vector
engagement maximization
psychographic targeting funnel
main character energy
```

## Selection Test

Before approving a phrase, answer:

```text
Is it useful in real life?
Can the viewer repeat it?
Does it help the topic?
Can it fit on screen?
Can it return later naturally?
Does it avoid sounding like a vocabulary card?
```

If the answer is weak, do not promote the phrase.

## Placement Rules

Put useful phrases where they support:

- the hook
- the section label
- the main metaphor
- a visual reveal
- WIT's reaction
- a repeated joke
- the final payoff

Do not stop the video to say:

```text
Today's vocabulary is...
```

Use the phrase as part of the actual video:

```text
The app is not really free. It just moves the price somewhere less visible.
```

## Repetition Rules

Repeat key phrases naturally.

Good repetition:

```text
Hook: not really free
Section 1: hidden cost
Section 2: the cost moves somewhere less visible
Payoff: free was only the easy entry
```

Bad repetition:

```text
Repeat the exact phrase every paragraph until it feels like a worksheet.
```

## On-Screen Rules

Useful phrase labels should be:

- short
- readable at mobile size
- visually connected to an object or WIT reaction
- shown on or just before the spoken cue
- kept on screen long enough to read

Do not show all `3-5` phrases at once unless the board is a final recap.

## Humor Rules

A useful phrase can be funny if:

- the object makes it literal
- WIT reacts to the phrase
- red markup corrects it
- the phrase returns with a worse meaning
- the phrase is attached to a normal situation that suddenly looks suspicious

Example pattern:

```text
Normal phrase:
easy entry

Visual joke:
WIT walks through a door labeled EASY ENTRY and sees five payment traps behind it.
```

## Final Payoff Rule

At least one useful phrase should help the ending.

The final insight should be easy to repeat:

```text
The app was not really free. Free was just the easy entry.
```

If no phrase can help the ending, the phrase list is probably decorative.

## Pass Standard

The useful phrase layer passes when:

- the phrases make the topic clearer
- the viewer can reuse them outside the video
- the screen stays clean
- the video never stops to teach vocabulary
- at least one phrase makes the final insight more memorable
