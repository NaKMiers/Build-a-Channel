# Shared Brain

This folder stores the durable memory and reusable systems for `Why It Works`.

Keep it small. If something belongs to one video, put it in `projects/<slug>/`.

## Structure

```text
channel/       current state, strategy, guardrails, collaboration, brand, workflow
systems/       compact reusable production systems
assets/        only approved reusable assets
```

## Read First

1. `channel/current-state.md`
2. `channel/channel-foundation.md`
3. `channel/channel-guardrails.md`
4. `channel/reference-channels.md`
5. `channel/learning-log.md`
6. `channel/codex-collaboration.md`

## Compact Systems

- `channel/production-workflow.md`: step order, project boundaries, quality gates
- `channel/brand-system.md`: channel visuals, WIT, thumbnail visual identity
- `systems/topic-packaging-hooks.md`: topic angle scoring, packaging, thumbnails, hooks
- `systems/script-learner-voice.md`: script style, English learner clarity, narration, voiceover
- `systems/visual-production.md`: reference boards, real-life assets, scene grammar, visual humor, HyperFrames boards
- `systems/audio-feedback-quality.md`: music, sound, mix, review, post-upload learning

## Asset Rule

Only keep reusable assets here when they are genuinely channel-wide.

Current reusable asset:

```text
assets/wit/poses/
```

This WIT folder should keep only `manifest.json` and the `24` transparent PNG pose files listed in it.

Video-specific assets belong in `projects/<slug>/assets/`.
