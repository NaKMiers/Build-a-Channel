# Render Motion Rules

Use these rules when building HyperFrames sections with the `render` skill.

## Voice Sync Rule

Everything on screen must describe the voiceover at that moment.

Before writing or changing animation:

- map each voiceover beat to exact board timing
- decide what appears, holds, and disappears for that spoken beat
- remove elements that explain an earlier or later line
- make cue-critical labels readable on the cue frame, not just starting to animate there

## Timing Order

Build timing in this order:

1. Create a hard-cut timing pass that matches the voiceover.
2. Verify the section visually against the voiceover.
3. Add transitions only where they improve continuity, clarity, or the joke.
4. Rewatch after transitions and adjust timing if the transition shifts the perceived beat.

## Transition Rules

- Do not use one default transition for every scene.
- Choose each transition based on the relationship between adjacent boards: continuation, reveal, contrast, cause/effect, punchline, or reset.
- The best transition should make two boards feel connected, like one idea moving smoothly into the next.
- If a transition makes the voice sync worse, use a simpler transition or a hard cut.
- Never protect a visual effect at the cost of narration clarity.

## Element Animation Rules

- Design entrance, hold, emphasis, and exit for every meaningful element.
- Tie element emphasis to spoken emphasis.
- If the voice stresses a word like `FREE`, `URGENT`, or `BUSY`, make the label land with a fitting action such as smash, stamp, snap, marker strike, shake, or pop-on-impact.
- Do not make every label use the same pop-in.
- Do not animate decorative elements while the viewer needs to read or understand the main point.
- Exits should clear space for the next spoken idea; they should not remove context before the viewer understands it.
