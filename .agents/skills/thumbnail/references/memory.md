# Thumbnail Memory

## Durable failure modes

- A small centered face surrounded by equal-weight objects has weak hierarchy.
- An abstract headline without a visible person, object, action, or consequence is slow to
  understand.
- Empty two-color backgrounds feel unfinished when they do not create depth or conflict.
- Repeating the same number in title, copy, and scene looks redundant.
- Five cosmetic variants do not test five click hypotheses.
