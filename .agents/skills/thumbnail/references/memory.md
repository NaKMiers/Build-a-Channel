# Thumbnail Memory

## Durable failure modes

- A small centered face surrounded by equal-weight objects has weak hierarchy.
- An abstract headline without a visible person, object, action, or consequence is slow to
  understand.
- Empty two-color backgrounds feel unfinished when they do not create depth or conflict.
- Repeating the same number in title, copy, and scene looks redundant.
- Five cosmetic variants do not test five click hypotheses.

No HumanPrice thumbnail has performance evidence yet.

## Explicit user feedback

- User approved the finance-board system after a visual audit of recent economics-channel
  thumbnails: oversized black header, thin red underline, white grid paper, central
  transaction, and sparse margin callouts. Use it as the default while retaining original
  HumanPrice subjects, palette, cast, and compositions.
- User rejected a generation that made the terminal and scene too dimensional and busy.
  The approved reference has a huge black two-line headline, thin red underline, simple
  flat cartoon people at a cafe counter, one readable central transaction, and a few
  isolated edge icons with arrows. Prefer this clean board hierarchy for every future
  thumbnail.
- Latest explicit feedback supersedes the sparse-board interpretation above. The user
  selected the former Mr. Finance hardware-store thumbnail as the mandatory reference and
  asked that every future thumbnail prompt bind it directly. Preserve its oversized
  headline, long red underline, hand-inked detail, dense coherent central environment,
  small embedded characters, and handwritten edge callouts. Change the subject, wording,
  branded content, and exact composition for HumanPrice.
- User rejected the single-word `OPTIONAL?` headline in the first Project 1 generation.
  The top headline must always be four to nine words, in no more than two lines: either a
  topic statement such as `THE ECONOMICS OF TIPPING` or a complete curiosity or consequence
  question such as `WHY DOES TIPPING FEEL REQUIRED?`. Never use a one-word or elliptical
  short-fragment headline.
