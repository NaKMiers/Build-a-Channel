# Scenes Memory

- Warm paper, clear depth planes, and story-specific props improve perceived authorship.
- Dense environments need a negative-space corridor around the focal action.
- Generated text is unreliable. Mission-critical numbers and labels belong in editing.
- A build chain should change one information-bearing element at a time.
- A chain break belongs between compositions, never between a plate and its variant.
- Exact crowd counts should be symbolic unless counting is the information task.
