# scenes - memory

Durable planning and prompt lessons for the current HumanPrice visual system.

## Composition and readability

- Warm paper, clear depth planes, and story-specific props improve perceived authorship.
- Dense environments need a negative-space corridor around the focal action.
- Density lives in the count of competing marks, not the count of ideas. A mechanism can
  remain simple when each beat adds one readable object to a stable composition.
- Exact crowd counts should be symbolic unless counting is the information task.
- Generated text is unreliable. Mission-critical numbers, names, and labels belong in
  editing. One or two optional words are safer than a sentence.
- Repeated abstract ideas need one stable physical device. Plant a scale, queue, funnel,
  receipt, ring, or gauge early and reuse it with changed meaning.

## Transcript interpretation

- When transcript cues split one sentence, derive each visual claim from the complete spoken
  sentence so fragment cues do not produce vague frames.
- Open a fresh mini-plate for each completed spoken thought when the idea truly changes. Use
  its split cues as variants only when they are meaningful steps in the same visual build.
- A script phrase describing a feeling is not automatically a drawing instruction. Preserve
  the meaning while respecting cast and visual constraints.
- A cited researcher who is not in the cast is usually better represented by the evidence or
  mechanism than by an invented person.

## Plate continuity and Flow inheritance

- A build chain should change one information-bearing element at a time.
- `expression change` alone is not a useful delta. Name the visible change precisely.
- A plate and its variants must keep surface, camera axis, cast placement, geometry, major
  objects, palette, and line hierarchy stable.
- Every variant must repeat the canonical surface-family wording. Shorthand can make the
  validator miss a surface or let the renderer drift.
- A chain break belongs between compositions, never between a plate and its variant, callback,
  or hold.
- After replacing a prompt range, inspect both records on both sides of each seam. A splice can
  silently swallow the break that protected the untouched scene.
- If an act boundary opens on a callback, restate the callback composition explicitly or move
  the break to the next true plate. Do not break its lineage merely to honor the chapter edge.

## Scale and verification

- Write and verify `visual-plan.md` before prompt prose. Rebalancing table rows is safer than
  rewriting hundreds of prompt lines.
- Work in chunks of about 25 cues and re-read the last three prompts at each boundary. This
  prevents scene-holding failures and late-file prompt shrinkage.
- Plan rows should be written against individual cues, not copied from an act-level label.
  Repeated meanings, repeated medium shots, and repeated generic deltas signal collapse.
- Prompt count, timestamp diff, and style-string counts do not catch missing blank separators.
  Always check for adjacent prompt lines because Flow splits records on blank lines.
- Normalize away timestamp and narration context, then compare prompt bodies. Exact duplicate
  bodies can survive count, timestamp, and delta checks while still generating duplicate frames.
- Source beat IDs and plate IDs are different namespaces. A non-plate Source points to an
  earlier beat, never merely to a plate name.
- Honest register or surface deviations caused by the script should be explained, not padded
  with decorative frames to satisfy a target band.
- Narrative build chains and Flow inheritance chains are different. A plan may have four to
  seven macro chains but still need a break before nearly every independent PLATE. Benchmark
  plate-break coverage, not chapter count.
