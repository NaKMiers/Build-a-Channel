# Cast Memory

- Reference sheets stay neutral and functional. Cinematic depth belongs in scene prompts.
- Distinguish supporting characters through silhouette, clothing shape, and one relevant
  prop, not stereotypes.
- Preserve `@YOU` face, hair, olive overshirt, terracotta undershirt, and proportions in
  every project.
- Do not create a character when an object or institution symbol tells the mechanism more
  clearly.
- When the locked protagonist sheet already supplies turnaround views and core expressions,
  restate the identity lock and add only episode-specific action poses and props.
- When a protagonist sheet establishes a simplified doodle-cartoon look, supporting sheets
  must inherit its flat color blocks, dot eyes, minimal facial marks, and broad silhouettes.
  Do not use semi-realistic faces, detailed facial anatomy, hair strands, or shaded materials.
