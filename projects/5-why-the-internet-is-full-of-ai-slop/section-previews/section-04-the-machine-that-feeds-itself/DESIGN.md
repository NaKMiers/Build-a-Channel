# Section 4 Design - The Machine That Feeds Itself

- Composition: `Section04Machine`, 1920x1080, 52.971s.
- Big idea: the incentive chain as a literal **self-feeding engine**. Five numbered steps land
  separately so an A2-C1 learner follows by ear; the engine motif teases dormant (4.1), roars as the
  loop closes (4.8), and is named in the verdict (4.9).
- 9 connected big scenes, one per beat, each on its own track with a short crossfade. Hard cuts +
  hard-show by default; impact motion (smash/pop/stamp) only on STEP pops, `$0`, `ATTENTION`,
  `FLOOD THE ZONE`, `THE MACHINE FEEDS ITSELF`, the SERVED + verdict stamps.
- Continuity device: a small top-right **loop-ring HUD** that lights one node per Step and completes
  on "the machine feeds itself."
- Bases: 7 fresh real photos (machine hall / vintage set / bright desk / casino / spotlight stage /
  CRT wall / mission control) + the deliberate engine-hall callback. Graded bright/warm/cool/dark;
  side scrim on the text half, light edge vignette - never a full dark wash.
- Mascot: one giant WIT per scene (~1/3-1/2 frame, high anchor, legs-only crop), pose + side varied
  every scene to match the emotional arc (sly -> presenting -> scheming -> boss -> lecturing -> manic
  -> disgusted -> dismayed -> deadpan).
- Type: PatrickHand handwritten labels + Segoe UI bold for STEP chips / kinetic words / stamps.
- Colors: `--gold #ffd23f` (money/engine), `--green` for `$0`, `--red` for struck/verdict stamps.
- Safety: engagement = generic slot machine, attention = generic balance scale (no real logos); the
  incidental DELL laptop logo on the 4.3 base is covered with a bezel-matching CSS patch.
