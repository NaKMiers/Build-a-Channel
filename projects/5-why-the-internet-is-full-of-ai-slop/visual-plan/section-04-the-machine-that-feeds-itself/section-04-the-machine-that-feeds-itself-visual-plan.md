## Video-Level Direction (for context - keep identical to master)

- Audience: A2-C1 English learners (interesting-English advantage).
- Renderer: HyperFrames (composites pre-made ISOLATED assets + transparent WIT poses).
- Visual grammar: a distinct vivid base per scene + a bespoke GENERATED hero + giant varied WIT + handwritten labels. Generate-forward; never reuse one base as a crutch (owner-directed 2026-06-28).
- Mascot: WIT - round bald white head, thick black outline, big glasses, flat white body. Transparent cutouts in `assets/poses/` (used directly). Big + high, varied side/scale/pose/emotion per scene.
- Tone on screen: dry, savage, a little unhinged; edge at the machine / the incentive, never the viewer.
- Section motif (NEW for S4, a deliberate callback to S3's slop-machine): **THE SELF-FEEDING ENGINE** - a circular contraption (PROMPT in -> grey slop out -> feed -> coins -> a return pipe loops the coins back to the prompt). It is teased dormant at the open (4.1), ROARS shut as the loop closes (4.8), and is labeled in the verdict (4.9).
- Continuity device: a small CSS **loop-ring HUD** in a corner gains one lit node per Step (1..5) and completes when "the machine feeds itself."
- Imagination rule: unlimited within copyright/law/YouTube community standards. Generate is the default for heroes; browse-real for grounding bases. Public figures/brands -> parody only, no real logos.

## Section Overview

- Section goal: explain the incentive chain step by step (the heart of the video). Five steps land separately so a learner can follow by ear: (1) making content got nearly free, (2) the platform pays for engagement not quality, (3) so the smart move is to flood the zone, (4) the algorithm can't tell slop from real and serves it anyway, (5) slop makes money that pays for more slop - the machine feeds itself. Close on the dry verdict: cheap + paid-by-attention + impossible-to-filter = of course it floods.
- Duration: `52.971s` (longest section). Timing ESTIMATED (no word-timings yet).
- Scene count: `9`.
- Scene-type rotation: noir setup / object-pile contrast / clean-cheat / role-as-platform slot machine / mascot-focus pivot text / barrage gag / blind-robot gag / motif loop-close / verdict-stamps.
- Mascot arc: sly setup -> respectful "the old way" -> scheming-cheap -> smug platform boss -> lecturing the thesis -> manic flood -> disgusted at the blind algorithm -> dismayed as the loop closes -> dry verdict (the "unimpressed-at-the-machine" beat the video has been building to).
