## Video-Level Direction (for context - keep identical to master)

- Audience: A2-C1 English learners (interesting-English advantage).
- Renderer: HyperFrames (composites pre-made ISOLATED assets + the transparent WIT poses).
- Visual grammar: vivid/surreal base per scene + bespoke generated hero + giant varied WIT on top; new scene ~per beat; vary EVERYTHING; never reuse one base as a crutch.
- Mascot: WIT - round bald white head, thick black outline, big glasses, flat white body. Transparent cutouts in `assets/poses/` (used directly). Big + high, varied side/scale/pose/emotion per scene.
- Tone on screen: dry, savage, a little unhinged; edge at the slop machine, never the viewer.
- Recurring motif (NEW, replaces sludge for this section): **THE SLOP MACHINE** - a grotesque content-grinder that eats real things and extrudes grey "slop". It opens the section and stamps it shut.
- Imagination rule: unlimited within copyright/law/YouTube community standards. Generate is the default for heroes; browse-real for grounding textures. Public figures / real brands -> parody only, no real logos.

## Section Overview

- Section goal: define slop with 3 vivid marks - (1) looks flawless then GLITCHES/melts (tells: six fingers, gibberish, "Coca-Coola"), (2) costs the maker nothing but CRUSHES you (time/attention/trust), (3) made by the thousand - a firehose of identical clones. Stamp: "CERTIFIED SLOP - a machine pretending to be a person, at full volume."
- Duration: `40.704s`. Timing pinned to REAL word-timings (`voiceover/section-03-what-slop-actually-is/section-03-word-timings.json`).
- Scene count: `9`.
- Scene-type rotation: machine intro / glossy reveal / glitch-meltdown / melting sign / parody ad fail / crush-pile / firehose flood / certified-slop stamp / masked-robot payoff.
- Mascot arc: announcer -> sarcastic awe -> horror -> baffled -> howling laugh -> flattened/dead -> blasted -> smug -> bone-dry.
