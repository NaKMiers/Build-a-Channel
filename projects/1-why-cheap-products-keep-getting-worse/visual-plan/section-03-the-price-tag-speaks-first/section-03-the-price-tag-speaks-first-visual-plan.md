## Section Goal

Explain the first mechanism in `33.429s`: the visible price is easy to read now, while future replacement cost is quiet, delayed, and hidden behind more attractive shopping promises.

## Source Inputs

- Script: `02-script.md`, `Section 3: The Price Tag Speaks First`
- Voiceover: `voiceover/section-03-the-price-tag-speaks-first/scratch-audio/section-03-the-price-tag-speaks-first-david23-am_eric-0.84.mp3`
- Script promise: `the price tag speaks before the hidden future cost can explain itself`
- Section duration: `33.429s generated audio; cue timings are estimated from marked-script pauses because no word-level timestamps were produced`

## Narration

```text
The first reason is that the price tag speaks first.

When you buy something, the price is easy to understand.

Nine dollars is nine dollars.

Your wallet can read that very quickly.

But the future cost is quiet.

It does not stand next to the product and say, "Hello, I am the replacement you will buy in three months."

That would be helpful.

Also, very bad marketing.

So products compete on the things you can see immediately.

Low price.

Fast delivery.

New color.

Extra feature.

A sale sticker that looks like it has personally saved your life.

But if the visible price has to stay low, something else may become negotiable.

Sometimes that something is tomorrow.
```

## Visual Direction

- Big-scene/cue rhythm: `4 persistent big scenes, 10 estimated cue states; the same hidden-tag base returns at the end so the section has memory, while Scene 3 deliberately breaks the tabletop/tag look`
- Big scene rhythm: `loud visible price -> quiet future cost -> visible promise competition -> tomorrow negotiated`
- Cue-state count: `10 estimated voice-synced cue states`
- Main visual metaphor: `a big bright price tag covers smaller future-cost tags`
- WIT emotional path: `tempted buyer -> fast wallet approval -> confused listener -> deadpan marketing judge -> overwhelmed shopper -> defeated tomorrow-owner`
- Real-life texture: `blank tag paper, receipt paper, plain cardboard box`
- Real image references: `3 sourced real-world images copied into this section reference folder`
- Generated/support assets: `1 direct generated support base for hidden future tags; the generated visible-shopping-promises image was inspected but skipped for direct use after review`
- Viewer attention strategy: `make the first idea visual before explaining it: the price tag literally talks first, then the hidden tags try to speak too late`
- Retention risk: `this section can become an abstract consumer-behavior explanation if it is only labels on a product`
- Visual fix: `turn Scenes 1, 2, and 4 into a mini trial where the loud price tag gets the microphone, then make Scene 3 a separate checkout promise arena so the visible-promise list does not feel like another tag photo`
- Red markup: `use red only for delayed/future evidence and final negotiable tomorrow stamp`
- Motion rule: `hard cuts between big scenes; inside each big scene use small cue reveals, tag flips, red stamps, or WIT swaps only`

## End-State Self-Check

- Final viewer memory target: `price is visible now; tomorrow is hidden behind it`
- Best paused frame: `Big Scene 4 at about 31.5s, with the big yellow price tag still visible, hidden tags labeled weak part / short life / hard repair / buy again later, and final red stamp TOMORROW`
- What render must not be forced to invent: `the hidden-tag composition, the visible-promise badge layout, WIT pose choices, label text, final tomorrow reveal, or where tags sit`
- What generated images solve: `the hidden-future-tag image gives the exact opening/final product-tag base that real photos did not provide`
- What real images still contribute: `material trust: real tag paper, receipt texture, and plain box texture keep the scene from feeling like a sterile diagram`
- What remains in HyperFrames: `all readable text, prices, red marks, speech bubbles, WIT placement, wallet prop, cue timing, and the CSS-built checkout promise arena for Scene 3`
