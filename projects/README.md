# Projects

This folder stores one `Why It Works` video per folder.

Use it for per-video work:

- topic intake
- research pack
- script drafts and revisions
- voiceover notes and audio
- title and thumbnail packaging
- visual plan
- HyperFrames source
- renders and review artifacts
- upload notes
- self-learning notes

## Standard Folder

```text
projects/<video-slug>/
  README.md
  00-topic-intake.md
  01-research-pack.md
  02-script.md
  03-voiceover.md
  04-packaging.md
  05-visual-plan.md
  06-production-board.md
  07-review.md
  08-upload.md
  09-self-learning.md
  assets/
  hyperframes/
  renders/
  voiceover/
```

Use [projects/_template](C:\ME\THINGS\Build a Channel\projects\_template) when starting a new video.

## Source Of Truth

For an active video, the `projects/<slug>/` folder is the source of truth.

Use `.agents/_shared/channel/` for channel-level memory, strategy, reusable workflow notes, and compact summaries.
Use `.agents/_shared/` for reusable tools, templates, workflows, HyperFrames systems, and shared assets.

## Continuous Improvement

After every review or upload, update the relevant project files first.

Then promote only reusable lessons into:

- `.agents/_shared/channel/learning-log.md`
- `.agents/_shared/` systems, templates, or workflows
- the relevant future skill memory when executable skills exist

The goal is simple:

`Every video should make the next video easier and better.`
