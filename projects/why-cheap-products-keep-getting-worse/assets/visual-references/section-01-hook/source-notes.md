## Section 1 Asset Rule

The hook should mix:

```text
real internet-photo texture + controlled generated bases + WIT + handwritten labels + red markup
```

It should not become:

```text
ugly SVG reference board, pure generated image mood board, or clean vector-only UI boards
```
