## Section Overview

- Section goal: demolish the "investment" story using its own postcard fantasy, land the
  video's reframe ("It is a purchase.") as one clean red-markup correction, transfer
  Ferrari status logic onto the trophy (generic red supercar, NO logo), put the bill on a
  `TAXPAYER` credit card, and plant "who pays" as the question the payoff (S8) answers.
  The receipt motif does NOT appear in this section - the trophy hero returns instead.
- Duration: `33.728s` (audio `section-02-reframe-david23-am_eric-0.81.mp3`)
- Timing source: `voiceover/section-02-reframe/section-02-word-timings.json`
  (whisper-tiny.en, generated 2026-07-02). Whisper hallucinated a DUPLICATE pass of the
  "Except the Ferrari... the credit card is yours" run with backward timestamps (a second
  copy restarting at 21.48); this plan uses the first pass through `yours,@27.48-28.14`
  and the continuation `the@28.06` + `taxpayers.@28.32-29.34`. Mishearings ("the
  taxpayers" = "The taxpayer's", lowercase "seen" = "SEEN") do not affect the timestamps -
  tokens are mapped to the real script words by position. Clamp the root/scene-2.5 end to
  the real `33.728s` - whisper's last-word end overshoots to 36.24.
- Scene count: `5` (a visible change every ~4-8s)
- Scene-type rotation: 2.1 wide postcard-fantasy gag -> 2.2 correction board (two-phase
  evidence markup) -> 2.3 glamour showroom gag -> 2.4 luxury-checkout object swap ->
  2.5 mascot-giant question closer
- Mascot arc in this section: sunbathing believer (floating inside the lovely story) ->
  eyes-closed truth-teller (the reframe) -> sunglasses show-off (the Ferrari flex) ->
  full panic (the card is HIS) -> narrow-eyed skeptic handing the viewer the question
