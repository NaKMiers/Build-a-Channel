# 04 Visual Plan

Video: `Why Everyone Pretends To Be Busy`

Status: `Step 8 visual plan`

Approved packaging:

```text
Title: Why Everyone Pretends To Be Busy
Thumbnail label: BUSY?
Thumbnail image: WIT trapped in a calendar cage while fake emergencies attack.
Recurring motif: fake emergency machine.
```

## Visual Style

- Renderer: `HyperFrames`
- Format: no-face board explainer
- Main grammar: `static drawing -> narration twist -> red markup or hard cut -> next static drawing`
- Text style: handwritten labels, red corrections, simple arrows, short caption words
- Dominant motif: calendar cage plus fake emergency machine
- Main WIT mode: suffering WIT, trapped, suspicious, defeated, overloaded
- Real-life texture: actual real-world photo layers first for desks, laptops, phones, calendars, sticky notes, and task cards; generated raster support only for impossible joke-specific images; WIT and handwritten labels sit on top
- Motion: hard cuts, small pop-in notifications, red marker draw, subtle WIT shake, simple progress bar reveal

## Visual Rules For This Video

1. Do not make WIT look lazy. The system should attack WIT first.
2. Keep `REAL WORK` visible as a recurring untouched object.
3. Use fictional UI only. No real app logos.
4. Labels should be short: `BUSY?`, `REAL WORK`, `URGENT`, `VISIBLE`, `THINKING`, `PRODUCTIVITY THEATER`, `FAKE URGENCY`.
5. When the narration gets abstract, return to a physical object: calendar, inbox, task card, notification, spreadsheet.
6. Every section needs one paused-frame joke or evidence object.
7. Do not build the video as vector-only. Follow the `Casually Explained` lesson: use actual real-world image texture as evidence, then draw the joke on top.

## Animation Notes

- Use hard cuts as the default transition.
- Use pop-in notification bubbles only when the narration names notifications, messages, or urgency.
- Use red marker draw for corrections: `NOT THIS`, `NOT EMOTION`, `ACTIVITY != VALUE`.
- Use one subtle WIT shake when WIT is buried or attacked, but avoid constant character motion.
- Dense explanation boards should move slower and hold longer.
- Punchline boards should stay visible for the beat after the line lands.
- If a cue-critical word is emphasized in the word performance map, make its label appear on or just before the spoken word.
