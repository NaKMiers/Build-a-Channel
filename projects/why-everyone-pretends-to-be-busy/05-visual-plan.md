## Visual Direction

- Renderer: `HyperFrames`
- Format: `1920x1080, 16:9`
- Main grammar: `static base photo -> voice-timed cue change -> red markup / hard cut -> next base`
- Script promise: `Why Everyone Pretends To Be Busy` — looking busy reads as important; real work/thinking reads as lazy
- Main motif: the calendar that fills with fake urgency and then becomes a cage; an ignored `REAL WORK` folder
- WIT role: audience surrogate, the system happens to him (panic → think → judged → trapped)
- Real-life texture: real public-domain photos (wall calendar, minimal desk) as scene bases
- Editor intent: few persistent big scenes, low cue count, WIT as the emotional subject, labels on the spoken beat
- Reference standard: real sourced images first (Wikimedia Commons), viewed before selection; generated images only as support (none needed for S1)
- Red markup style: red URGENT dots, red contradiction "?", red LAZY? stamp — each targets a specific object
- Motion rule: ordinary labels hard-show; impact reserved for contradiction, URGENT swarm, LAZY? stamp, cage slam
