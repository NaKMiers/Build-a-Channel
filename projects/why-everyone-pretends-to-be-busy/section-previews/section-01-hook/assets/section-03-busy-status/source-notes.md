# Section 3 Source Notes

Video:
`Why Everyone Pretends To Be Busy`

Section:
`03 Busy Became Status`

## Source Decision

Used gstack `/browse` for quick reference research.

- Openverse image search hit a Cloudflare verification page and was not used.
- Wikimedia Commons media search loaded, but the headless text view did not expose useful individual image candidates for this section.

Final production decision:
use generated project-owned real-life-ish images for Section 3 to avoid real platform logos, private workplace data, and unclear licensing.

## Generated Images

Generated with Codex built-in `image_gen`, then copied into the shared video-level asset library:

- `generated/status-badge-desk-generated.png`
- `generated/busy-small-talk-generated.png`
- `generated/demand-value-board-generated.png`
- `generated/generic-professional-network-generated.png`
- `generated/meeting-tower-generated.png`
- `generated/near-the-work-generated.png`

All prompts requested:

- photorealistic office/desk textures
- no people
- no logos
- no brand names
- no readable text
- no private data
- no watermarks
- open space for HyperFrames handwritten labels and WIT overlays

## Use

These images support Section 3's idea that busyness became social proof:

- status-desk for `BUSY = STATUS`
- small-talk table for `BUSY` as an answer to `How are you?`
- demand corkboard for `DEMAND = VALUE`
- generic professional network screen for the LinkedIn-adjacent joke without using the real logo
- meeting tower for fake calendar/document inflation
- near-the-work desk for the final `NEAR THE WORK` payoff
