# Video Projects

This folder stores the working memory for every individual `Why It Works` video.

Use this folder for per-video work:

- idea selection
- research brief
- script drafts
- packaging
- visual plan
- production board
- assets
- voiceover notes
- render notes
- post-upload review

## Rule

Every new long-form video gets one folder:

```text
video-projects/<video-slug>/
```

Example:

```text
video-projects/why-free-apps-never-really-free/
```

## Standard Files

Each video project should use this structure:

```text
README.md
00-idea.md
01-research.md
02-script.md
03-packaging.md
04-visual-plan.md
05-production-board.md
06-review.md
assets/
voiceover/
renders/
```

## Source Of Truth

For an active video, the `video-projects/<slug>/` folder is the source of truth.

Use `docs/` for channel-level memory, strategy, reusable workflow notes, and compact summaries.
Use `common/` for reusable tools, templates, skills, Remotion systems, and shared assets.

## Continuous Improvement

After every video, update:

- `06-review.md` inside the video folder
- `docs/learning-log.md` for the reusable lesson
- common templates or tools if the lesson improves future production

The goal is simple:

`Every video should make the next video easier and better.`
