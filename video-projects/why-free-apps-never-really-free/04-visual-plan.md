# 04 Visual Plan

Status: `Detailed storyboard draft for approval`

This replaces the earlier high-level visual plan.

Purpose:
turn the approved script into a Remotion-ready visual storyboard.

Do not generate new voiceover, scene JSON, or renders until this storyboard is approved.

## Production Principle

Working rule:

`Simple style, many beats.`

This video should keep the drawing style simple, but the screen should change often.
For a `3-4 minute` video, the goal is not 10 static scenes.
The goal is a small number of reusable visual systems with many micro-beats inside them.

## Timing Note

The approved script is about `745 words`.

Runtime depends on narrator speed:

- fast narration: about `3:45-4:15`
- slower narration: about `4:30-5:00`

Before final production, run a short voice test.
If the full generated voiceover is longer than `4:00`, trim the script before rendering instead of forcing the visuals to stretch.

## Visual Thesis

The whole video should make one idea visible:

`The checkout did not disappear. It moved somewhere less visible.`

Visual story:

1. Free apps arrive like gifts.
2. Wit accepts the free offer.
3. The system starts printing hidden costs.
4. Attention becomes inventory.
5. Habit becomes value.
6. Freemium removes pain for a price.
7. Lock-in makes leaving annoying.
8. The hidden checkout is revealed.

## Style Rules

- simple 2D graphics
- warm off-white background
- charcoal outlines
- orange/yellow for `FREE`, receipts, warnings, and costs
- teal for system arrows, pipes, loops, and app machinery
- no real app logos
- no scary hacker/privacy visuals
- no long text blocks
- no detailed backgrounds unless they explain the joke

## Character Rule

Use Wit moderately.

Wit should be in about `60-70%` of the video, but the main character is still the hidden system.

Wit's receipt tie is the recurring visual metaphor.
It grows as the video reveals more hidden costs.

Receipt tie labels:

- `ads`
- `attention`
- `minutes`
- `streak`
- `upgrade`
- `limit`
- `storage`
- `subscription`
- `lock-in`

## On-Screen Text Rules

Use short labels only.

Good:

- `FREE`
- `FREE?`
- `easy entry`
- `attention`
- `inventory`
- `open`
- `tap`
- `streak`
- `$9/mo`
- `lock-in`
- `hidden checkout`

Avoid:

- full paragraphs on screen
- tiny labels nobody can read
- too many labels at once
- real brand names or logos

## Thumbnail Connection

The final payoff and thumbnail should use the same visual idea:

- phone or free button
- `FREE?`
- hidden checkout
- receipt trail
- Wit staring at it

This makes the video feel like it pays off the click.

## Production Risks

- If every beat becomes a separate custom illustration, production will become too slow.
- If beats are too static, the video will feel like slides.
- If Wit appears too much, he will compete with the explanation.
- If the voiceover is too long, visual pacing will feel stretched.
